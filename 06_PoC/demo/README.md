# STTP 科学之间 · 探索版与工程版

这是独立的本地前端预览。精选部分有 3 个主题、20 个节点、24 条联系；也可选择「原图库」搜索此前导入 SQLite 的 9,750 个节点和 48,813 条关系快照。所有内容仍在完善，供本机试用，不能将页面显示视为科学结论或发布许可确认。原始图文件未被修改。此前发现的 ATP 结构与分子式矛盾尚未在原图库修复；原图库页面隐藏该节点公式并显示提示，数据库中仍保留原始记录。

## 启动

Windows 可双击 `start_demo.cmd`，保持窗口打开，然后访问探索版：

<http://127.0.0.1:8773/demo/>

左侧底部可选择探索版或工程版（原有系统），也可直接访问 `http://127.0.0.1:8765/`。工程版右上角可返回探索版或填写反馈。窄屏时版本入口位于页面顶部导航下方。

在项目根目录运行 `python 06_PoC/demo/launcher.py`，需要 Python 3.11 和原工程版依赖（见根目录 requirements）。Windows 启动脚本使用 `py -3.11`。两个服务仅绑定本机，Ctrl+C 停止由启动器创建的进程；若工程版已单独运行，启动器会复用且不会停止它。端口 8773 或 8765 被其他服务占用时先关闭占用程序。修改 `data.json`、词典或服务端代码后须重启本地服务。服务仅供本地开发，不用于公网生产。需保留 `06_PoC/vendor/` 中的依赖及许可文件；若图谱组件缺失，探索版文字列表仍可导航。

干净检出不包含完整原图：工程版启动器会在原图缺失时使用仓库内发布样例，探索版原图库搜索需自行提供完整原图并构建 SQLite；精选主题仍可使用。

原图库模式需要 `db_work/original-graph-probe.sqlite`。如文件不存在，在项目根目录先运行 `python 06_PoC/demo/database_probe.py build`，然后启动服务；构建只读 `06_PoC/etl/normalized.json`，拒绝覆盖已有数据库。没有数据库时仍可使用精选内容。数据库是导入快照，不自动同步原图更新。

## 使用过程

1. 首页选择主题，或者选择「原图库」并搜索「氧」「H₂O」「PV=nRT」「压力」「水分子有几个原子」。可选择全部、元素、分子、公式；选择「精选内容」则搜索 20 个策展节点。
2. 图谱与下方列表显示当前节点及一跳关系，每批最多 8 条。若有更多，可按「上一批／下一批」切换；学科联系也随当前批次变化。点击节点、关系卡片或主题路线中的步骤切换节点。
3. 查看右侧或下方详情：解释、公式、论文线索、条件、来源和同页各科的联系。原图库中论文可能仅是文本提及或算法候选，关联有待核对；没有相关内容时显示为空状态。原始关系仅按相邻节点领域归类，附带原始关系类型，不能当成新的科学推导。
4. 使用「上一步」或路径上的节点返回，打开来源链接核对。未审核内容已标记待复核。
5. 点击「提供反馈」，填写日常说法及其意思，复制或下载文本交给项目组；不会自动上传，也不会直接加入词典。词典位于 `daily_terms.json`，应由项目组检查、补充并重启服务。

## 版本试用统计

两个版本均有「试用统计：关／开」按钮，默认关闭。打开后，只向本机服务提交日期、版本、固定事件类型和有限时长；本机汇总表位于 `db_work/usage-metrics.sqlite`。探索版点「查看统计」可以比较版本进入、切换、点击、搜索、页面可见时长和部分功能按钮使用次数。工程版点击「反馈」会进入探索版的本地反馈表单，内容需由用户选择复制或下载后自行交给项目组。

统计表不保存搜索原文、反馈内容、身份或 IP，不跨电脑自动汇总。浏览器保留的选择可在各版本分别关闭；从探索版切换时会按探索版当前设置启动工程版统计。关闭后仅停止后续统计，已存汇总数据仍保存在本机。单独运行原工程版服务时，其原有控制台请求日志可能包含查询内容和本机地址；启动器启动的工程服务将输出丢弃。

计数只覆盖主动开启统计的访问，不是独立用户数；按钮点击不证明操作成功；时长是浏览器标签页报告为可见的时间，可能包含挂机或窗口失焦，未能发送的事件也可能漏记。工程版的搜索计数目前覆盖「查候选」按钮，不覆盖所有键盘操作。要判断真实需求，还需要有用户授权的访谈、反馈与任务完成结果，不能仅凭时间判断偏好。

## 当前边界

- 精选数据在服务启动时载入内存；原图库从本机 SQLite 索引按需查询。节点关系每批最多 8 条。原图库搜索结合字符串匹配和小规模手写词典，最多汇集 200 条普通文本匹配，不是向量检索或通用自然语言理解，公式等价性也未验证。
- 当前仅收录两篇不同论文，分别介绍查理定律实验和比尔—朗伯定律的校准问题；它们是相关研究或教学论文，不一律等于公式的原始发现论文。部分论文可能需要付费。所有关联、简介和再发布许可仍需复核。
- 本地内容为简单 Unicode 公式展示，尚未实现通用 LaTeX 渲染、公式演算、图像导出、账户或 AI 问答。
- 窄屏和桌面已进行有限的真实浏览器测试；不代表已在所有设备、浏览器及辅助技术上测试完成。
- 节点与关系及新增讲解的审稿、权限、补齐学科资料、检索评测和受控发布是下一阶段工作。部分领域、英文数据、含糊关系及缺失来源仍会影响体验。
- 原图库候选可使用 [原图库候选审核操作指南](原图库候选审核操作指南.md) 中的本机工具隔离整理；候选不会自动进入 Demo。
- 可参照 [草稿修订与审核指南](草稿修订与审核指南.md) 编写独立展示内容、建立新修订并核对审核指纹；当前真实样本仍待审，不自动发布。

## 可复现验证

先启动本地服务，然后在项目根目录：

```powershell
python '.\06_PoC\demo\test_demo.py'
python '.\06_PoC\demo\test_api.py'
python '.\06_PoC\demo\test_database_probe.py'
python '.\06_PoC\demo\test_usage_metrics.py'
```

第一个脚本校验数据 ID、论文元数据、来源/条件、ATP 排除和资源白名单；如本机存在评估基线，还对照原始文件哈希，否则跳过该部分。原图库测试缺少本地数据库或原图时会标记跳过。浏览器脚本需要另行安装 Node.js、Playwright 和 Chromium，可通过 `STTP_BROWSER_PATH` 指定浏览器，截图写入系统临时目录。测试不会修改原图，测试通过不能证明科学内容正确。

## ① 专家补做项

数学、物理、化学专家应核实公式定义域、单位、物质状态和每条跨学科关系，不能仅靠机器对账；教育和无障碍专家应与真实用户一起检查理解、键盘和屏幕阅读器。若独立审查发现表达错误，应改正或移除，不能为图谱连通而保留。
