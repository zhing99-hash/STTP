# STTP 科学之间：本机 Demo 验收记录

日期：2026-10-29。下列原始记录适用于 `sttp-explore-demo-0.1`，后续更新见文末的 0.2 记录。这是供负责人和小范围内部评阅的开发预览，不是公开发布版，也不代表完整项目通过验收。

## 实现结果

- 首页提供关键词搜索及「一杯水里，有多少分子？」「气体受热，为什么会膨胀？」两条主题路线。
- 独立内容包包含 10 个节点、11 条关系；图谱只绘制当前节点的一跳邻居，并提供同等可点击的文字列表。
- 节点详情同页展示数学、物理、化学、生物、天文、工程六个配置学科，有联系时直接列出解释、条件和来源，无内容时显示空状态。可以点击联系继续探索，查看路径、返回以及主题步骤。
- 所有内容标明为待独立科学及许可复核；关系区分正向和反向浏览，不为填满学科编造关系。内容包保留部分原图节点的 ID 映射，其他内容是新的独立 Demo 数据。
- 本机反馈表单提供复制、下载选项，不自动上传。服务只提供 Demo 白名单文件与现有 Cytoscape 依赖。

## 本次验证与证据

2026-10-29 使用 Python 3.11.9 运行 `test_demo.py`，通过：主题、节点及关系数量；ID、来源和适用条件；原节点映射与 ATP 排除；5 项允许的 HTTP 资源、5 项拒绝的路径；4 项原始文件与基线和既有快照的 SHA-256 对照。基线位于 `review_20261028_full/demo_baseline.json`。该结果只覆盖四个文件，不代表对完整数据集逐一核验或完成全量备份恢复测试。

使用 Node.js 24.22.1 对 `app.js` 做语法检查，通过。真实浏览器中操作了首页、两条主题、图上节点、文字列表、节点详情、关系说明和来源链接展示、路径返回、重复选择主题、中英文搜索及无结果提示；并以 390×844 窄屏窗口检查主题切换、返回和搜索。反馈弹窗已检查打开、输入、关闭；复制到剪贴板和下载文件的实际结果本轮未验证。浏览器检查并非全浏览器、全设备、键盘或屏幕阅读器的完整无障碍测试。

测试程序通过不证明公式、引用、科学关系、第三方许可或学习效果正确。原项目此前发现的 ATP 数据问题仍待原图库单独修复，本 Demo 不包含 ATP。

## 现实限制和后续步骤

1. 当前一次加载小型 `data.json`，仅绘图范围限制为一跳；尚未接入完整图库，尚无大数据按需分页、搜索索引或在线更新。按正式版本需要设计查询 API、范围限制、审查状态和版本化发布数据集。
2. 请独立数学、物理、化学专家逐条核验节点、关系、公式、定义域、单位、原始方向、解释及来源，留下审稿人、日期、问题和处理结果；遇到反例须更正或撤下。来源链接并非专家背书。
3. 回到 BIPM 的原始定义、相关原始论文/实验及各数据集的原始发布方，核对出处、具体支持范围与可再分发许可。逐条建立授权记录和发布清单，不能将项目现有中间数据当作一手实验记录。
4. 邀请科学爱好者完成无引导试用：从问题进入、解释一条跨学科联系、找到来源并继续探索；记录成功率、困惑和可复现问题。完成独立专家和权利审查后再决策受控公开试用。
5. 加入独立复核、公式边界与量纲检查、浏览器自动化与辅助技术测试；补测反馈复制/下载、大数据性能与数据回滚。将外部审稿记录和用户任务证据作为可反驳的验收依据。

启动和用户操作见 [README](README.md)；原计划见 [功能清单](../../review_20261028_full/STTP_Demo开发计划与验收清单_20261029.md)。

## 0.2 更新与验证（2026-10-29）

新增本机只读配置、搜索和节点关系接口。服务启动时仍将全部小型示例数据读入服务端内存，前端请求时分页；每批最多显示 8 条关系，搜索也支持分页。接口提供总数和下一页偏移，限制单页不超过 20 条。当前示例节点最多 5 条关系，尚不足以自然触发前端的关系分页控件；接口测试以每页 2 条检验了完整分页和反向关系，不能据此宣称前端多页流程已通过浏览器测试。数据库索引、海量数据性能和线上接口尚未实现。

水主题补充给定 250 g 纯水的示例；更换摩尔质量和摩尔定义引用，并修正热力学温度的展示。来源查阅记录及待专家填写表格见 [科学内容核对与试用记录模板](科学内容核对与试用记录模板.md)。PubChem 页面本次访问被验证页拦截，其具体内容未核对。

测试：Python 3.11.9 接口测试共 5 项通过，包含配置、搜索和关系分页、非法参数、反向关系、水例子算术；原有白名单和 4 项原始文件哈希校验通过。Node.js 24.22.1 前端语法检查通过。浏览器中检查新版首页、水主题、摩尔质量与阿伏伽德罗常数详情、路径返回和英文搜索。该轮未重复完整移动端、图形节点点击、剪贴板和下载测试。

新版默认地址为 `http://127.0.0.1:8773/demo/`，以避免旧服务 8772 与新代码不兼容。内容文件被服务器启动时加载，改动后需重启服务。独立学科审稿、许可审核和独立用户试用均未完成，故本次依然只是开发预览。

## 原图库候选审核工具（2026-10-29）

新增 `curation.py`，可只读统计、搜索原图，按 ID 生成隔离候选并列出审查缺项。创建 `pilot-with-relations-20261029.json`，含原图 4 个节点及其间 2 条关系；节点、关系共 6 项，各缺科学和许可审查，合计 12 项待补记录。不存在的原图关系不会被自动推断。原图库和 Demo 展示内容未由工具修改。

Python 3.11.9 合成数据单元测试 6 项通过，覆盖待审默认值、输入错误、原文篡改、审核字段缺失、审核结构模拟和关系端点缺失。模拟审核只是验证字段逻辑，不是实际专家审核。真实服务测试通过，包括拒绝直接访问该候选 JSON；4 项原文件哈希对照与原有基线一致。工具不验证审稿人身份或许可真伪，不执行发布；完整工作步骤和限制见 [原图库候选审核操作指南](原图库候选审核操作指南.md)。

## 草稿修订与内部候选包（2026-10-29）

新增 `drafts.py`，从候选创建独立可编辑草稿，可复制修订、清空审核记录，检查原始摘录、草稿内容、节点与关系方向，并将审核指纹绑定草稿与关系端点。已创建基于 4 个节点、2 条关系的预填示例；其中原图温度符号与 Demo 热力学温度的映射仍是待审工作假设。真实样本有 12 项科学或许可审核缺失，实际调用 `bundle` 已拒绝生成文件。

Python 3.11.9 的 8 项合成数据测试通过，覆盖待审拒绝、模拟完整字段生成内部包、内容变化使关联审核失效、原文/关系方向变化、无效来源、篡改候选、附加字段和版本复制。模拟审稿人不构成真实审稿。服务测试通过，包括拒绝访问草稿文件；4 项原始文件哈希与基线一致。该工具无身份认证或发布功能，格式通过不证明科学、许可和人员身份，内部包也尚不能直接作为 Demo 数据使用。详见 [草稿修订与审核指南](草稿修订与审核指南.md)。

2026-10-30 运行 Python 3.11.9 的接口 6 项测试，检查数据完整性、4 项原始文件基线、白名单和 7 项阻止访问的路径，均通过。Node.js 24.22.1 语法检查通过；通过本机 Edge 和 Playwright 自动检查新主题、图谱画布点击、公式及论文卡片、跨学科跳转、返回、关系分页及 390×844 窄屏操作。浏览器检查覆盖有限路径，不代表无障碍或全部浏览器验收。

论文元数据分别对照 ACS 出版页和 PMC 原文；如论文网页需付费，不代表项目提供全文。新增的科学讲解、跨学科关系、许可和学习效果仍需独立复核。当前小样本仍非完整图库查询，也未解决原图库 ATP 问题。

## 0.4 本机原图库检索与日常用语（2026-10-30）

网页增加「原图库／精选内容」和「全部／元素／分子／公式」筛选，通过只读 SQLite 查询原图快照，按节点加载一跳关系；原始数据按来源和原始关系类型展示。数据库覆盖导入时的 9,750 个节点、48,813 条关系，不代表每个非标准提问都可命中。增加 `daily_terms.json` 作为可维护的检索词典；匹配是候选线索并给出需要澄清的条件，无自动训练或语义模型。用户可填写日常说法和意思，下载或复制反馈；无自动上传。原图已知 ATP 节点的结构与分子式矛盾仍在数据库中，页面隐藏该节点公式并提示，不能视为修复。

Python API 测试 10 项通过，包含中文氧元素、H₂O 分子、PV=nRT、自然语言候选、原图一跳分页、类型过滤、已知 ATP 和数据库文件不被直接下载。检查 9,750 个原始节点均可转换成界面数据，不代表内容均有解释。Edge 自动化检查元素搜索、自然语言搜索、节点详情、关系翻页、历史、本地反馈下载和窄屏；原有主题与论文流程复测通过。SQLite 与原始文件哈希、数量及三个示例节点对照通过；原始文件四项基线对照通过。尚无独立用户测试、真实问题准确率评测、生产负载或完整科学和许可审核。

## 探索版与工程版及本机统计（2026-10-30）

新增双版本入口，一键启动器启动或复用原有工程后端，并启动探索版服务。工程版保留原系统任务查询与图谱；右上角提供返回和反馈入口。默认不启用试用统计；主动开启后，按版本、日期和固定事件聚合本机点击及标签页可见时长，不采集搜索原文、反馈内容、身份或 IP。统计表不会自动上传。单独运行原工程版服务仍可能输出带查询的控制台日志，不应与统计表混为一谈。

测试：从停止状态运行启动器，两个本机端口均正常；通过 Edge 自动化检查默认关闭、同意后双向切换、工程版 `water` 候选查询并生成子图、工程版反馈跳转、前台计时事件、统计展示以及关闭后不再发送。浏览器测试使用拦截器和模拟统计数据，未写入实际用户统计；后台聚合及无效输入使用临时 SQLite 的 2 项测试通过。仅验证受测路径；统计不是用户数，也不证明操作成功、有效时长或用户偏好。
