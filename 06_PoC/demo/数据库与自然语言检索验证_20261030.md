# STTP 本地数据库与自然语言检索验证

日期：2026-10-30。此文记录本机技术试验，不表示 Demo 0.3 已接入完整图库或具备科学问答能力。

## 数据库试验

使用本机 Python 3.11.9 自带的 SQLite 3.45.1、FTS5 trigram，从 `06_PoC/etl/normalized.json` 创建 `db_work/original-graph-probe.sqlite`，导入 9,750 个节点和 48,813 条关系；数据库文件 115,900,416 字节。节点、关系保存原始 JSON 并建检索和关系索引；记录原文件 SHA-256 `fec51bf0f20112cb369e374f89dfe0d1fe798ee38bfbef9d4a2ff0e76cc10ea0`。数据库是某次导入快照，不随原图自动更新。

此前项目本身已有 Neo4j 和本地 NetworkX 的设计，但本次没有测试 Neo4j 连接、导入、运行或生产负载。SQLite 是本机可复现的验证手段，尚不证明未来无需图数据库。数据库含原始内容及已知问题，限本机内部审查；试验检索对已知 `BC:mo:atp` 隐藏公式并提示结构与分子式矛盾，但数据库本身仍保存原始值，不能把它直接公开或当作完成修复。

现有 0.3 网页服务仍只使用独立的 `data.json`，没有使用该 SQLite。页面白名单拒绝直接下载数据库文件。项目原始文件没有改写；导入记录的内容源不等于原始论文、权利证明或独立验证。

## 实际查询和局限

试验索引支持 ID 精确匹配、原图字段的连续文本匹配，以及 4 组手写规则；不会联网、不会调用大语言模型。中文短于 3 个字符时走简单扫描；长问题当前尝试完整连续文本，并非分词或语义理解。FTS5 trigram 的官方说明见 [SQLite 文档](https://www.sqlite.org/fts5.html#the_trigram_tokenizer)。

| 实测输入 | 返回 | 解释 |
|---|---|---|
| `TH:fo:ideal_gas` | 理想气体状态方程 | ID 精确匹配 |
| `气球受热体积变大是什么原因` | 查理定律、理想气体方程；提示补充压强和气体量 | 因为预先手写了「气球 + 受热」规则，不能视作通用自然语言理解 |
| `水分子有几个原子` | 无结果 | 证明完整句子无法可靠匹配已有英文名 Water，不代表库中没有水 |
| `ATP` | 返回候选，ATP 节点标注已知矛盾并隐藏公式 | 只是在检索输出中限制，库中原始记录并未修复 |

上述只是刻意选择的少量例子，不能推算真实用户的准确率、召回率或响应时延。代码对每项给出匹配原因，但没有经校准的置信度或精确性保证。

## 自然语言检索建议

用户描述的现象可能对应多个模型，不应保证“总是精确命中唯一公式”。建议分阶段：

1. 收集取得用户同意的真实问题，建立同义词、别名、中英文和物理量词典；维护学科、量、符号、单位和适用条件，保留表达歧义。
2. 并行召回：词法检索、经评测的语义向量检索、结构化符号/单位/公式检索；对公式做安全解析，符号相同不代表物理意义相同。三角索引不是中文语义模型。
3. 根据用户场景及证据重排，显示多个候选、匹配依据、来源与适用条件；例如气球受热应询问压强和气体量，不能一律断定恒压。
4. 对可信候选扩展一跳或有限跳关系，分别核查节点、关系与论文关联，展示审核状态。没有足够证据时明确找不到或请求补充；AI 只可基于可追溯资料辅助解释，不能把生成内容直接写入图谱。
5. 若考虑向量检索或 Neo4j，请验证部署版本和索引能力，不以示例代码替代本机端到端验收。Neo4j 官方说明：[向量索引](https://neo4j.com/docs/cypher-manual/current/indexes/search-indexes/vector-indexes/)。

## 专家需要补做和独立验收

- **原始材料**：真实用户原始问题与场景（取得同意并保护隐私）、权威单位定义与实验记录、原论文及上下游数据许可；保留用户原句，不只用人工整理后的标准词。化学核查还需原始结构、质子化态和反应记录。
- **方法**：由物理、化学、数学专家和教育用户分别对题目标注可接受结果、所需条件和反例，形成按用户或任务分组的独立测试集，避免同义改写泄漏到训练/规则集。对不同问法、歧义、无答案和已知错误分别测 Recall@k、Precision@k、MRR、错误自信、条件识别和拒答质量；记录各类问题的数量与置信区间。指标目标须根据试用确定，目前无真实评测结果。
- **独立证明**：不参与开发的专家重复核对节点、关系和论文；未参与标注的用户完成探索任务；独立团队复现数据导入、查询、失败案例、性能和版本哈希，并检查许可。可通过原始记录和反例推翻某条映射。

## 复现

在项目根目录的 PowerShell 中运行：

```powershell
$sttpPython = '.\review_20261028_full\python311\python.exe'
& $sttpPython '.\06_PoC\demo\database_probe.py' search '气球受热体积变大是什么原因'
& $sttpPython '.\06_PoC\demo\database_probe.py' search '水分子有几个原子'
& $sttpPython '.\06_PoC\demo\test_database_probe.py'
```

首次无数据库时运行 `database_probe.py build`；文件已经存在时拒绝覆盖。需要更新时，应另行保存或明确处理旧快照后再构建；不要直接删除原始图文件。现有导入程序为本机工具，不提供数据库迁移、访问控制、并发写入或正式发布机制。
