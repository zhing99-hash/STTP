# 公式拓扑知识图谱 · 开发落地路线图

> 项目目标：构建跨学科（数学 / 物理 / 化学）的**公式拓扑知识图谱**。
> 节点 = 公式 / 概念 / 物质 / 反应；边 = 推导依赖 / 量纲一致性 / 反应关联。
> 核心能力：拓扑可视化 + LLM 生成候选关系 + 符号计算自动校验闭环。
> 所有产出目录：`workspace\01tuopu\`

---

## 一、总体技术架构（四层，对齐已验证 ACM 方案）

```
┌─ 交互层      D3.js / Cytoscape.js（拓扑浏览、按置信度过滤、假设提交）
├─ 推理生成层  LLM 生成候选关系 + GNN 依赖推断 + SymPy / pint / RDKit 符号校验
├─ 知识层      Neo4j（生产）/ NetworkX（原型）：节点 + 边 + 置信度属性
└─ 数据层      多源采集 + 解析 + 去重 + Schema 标准化
```

架构验证依据：对应一篇 ACM 论文所述高级数学内容自动化构建平台（数据层多源异构采集去重 / 知识层 Neo4j / 推理层 GNN+LLM / 交互层 D3+Cytoscape），其测试中 API 调度成功率 99.4%、模块间数据一致性 98.9%。MathMorph 项目亦验证公式双向转换（自然语言 ⇄ 解析字典 ⇄ NetworkX ⇄ SymPy）。

## 二、数据源矩阵

| 学科 | 数据源 | 规模 | 格式 | 图中角色 |
|---|---|---|---|---|
| 数学 | MathXiv / ArxiTeX KG | 每论文 1 JSON | JSON（节点+证明+依赖边+definition bank） | 公式节点 + 推导边（最贴合） |
| 数学 | uw-math-ai/math-graph (HF) | formal 1.05G / informal 2.37G / statement 5.04G | CSV | 直接导入依赖边 |
| 物理 | PhysicsBabel / Vashy | 2,325,320 方程 | equation+符号+domain+命名定律 | 量纲齐次性 → 边生成逻辑 |
| 物理 | physicslibrary.org FundamentalFormulas | 几 KB/文件 | XML | 辅助校验源 |
| 化学 | ElementKG 2.0 | >100万反应 / >1000万物质 | KG | 超图：反应关联多物质/官能团 |
| 化学 | ReactionAtlas | 12,542 化合物 / 21,150 反应 + TS/IRC | PostgreSQL 26G | 量子化学底层 |
| 化学 | Reaction-QM | 百万级 QM 计算 | CSV+HDF5 | 电子能量标注 |
| 通用 | Wikidata | 130G dump / 105G Main Graph | JSON | 真理源：元素/属性/定义锚定 |

核心策略：**分而治之**——数学靠引用/推断依赖，物理靠量纲齐次，化学靠反应超图，三者用 Wikidata 做概念对齐层。

## 三、分阶段实施路线

| 阶段 | 名称 | 周期 | 目标交付物 | 退出标准 |
|---|---|---|---|---|
| **Phase 0** | 范围确认 & 技术基线 | ~1 周 | 图 Schema v0.1、数据字典、技术基线与环境文档 | 四层架构与数据模型冻结 |
| **Phase 1** | 单源 PoC 原型 | 2~3 周 | NetworkX 加载 MathXiv 样例 → 拓扑出图；sample 数据 + 主脚本 + HTML 原型 | 端到端跑通"源→图→可视化" |
| **Phase 2** | 多源接入 & 图库化 | 3~4 周 | 数据源接入规范、ETL 管道设计、Neo4j 部署+ETL | 多源统一图库 + 查询接口 |
| **Phase 3** | 推理与验证闭环 | 3~4 周 | 三道校验（配平/量纲/数学依赖）、LLM 假设生成+置信度 | 校验服务 + confidence 字段落地 |
| **Phase 4** | 可视化与交互 | 2~3 周 | Cytoscape.js 拓扑浏览、过滤、假设提交流程 | Web demo 可用 |
| **Phase 5** | 科研级扩展（可选） | — | math-graph 全量、GNN 推断、ReactionAtlas 接入 | 规模扩展验证 |

**MVP-first 原则**：Phase 1~4 先走高中/单学科可控规模（几百~几千节点）验证路径，Phase 5 再扩展至科研级全量（GB 级数据集），先采样 1% 跑通管道。

---

## 四、验证闭环（不可跳过，内置为管道关卡）

1. **化学**：方程式配平检查（原子守恒，RDKit）
2. **物理**：量纲齐次（PhysicsBabel 本身已保证；自生成关系必须重新用 pint 校验）
3. **数学**：`显式引用 explicit_citation` vs `LLM 推断 llm_inferred` 必须分色/分权重标注，不可靠边（confidence < 阈值）降权

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 数据规模大（math-graph 8G+） | 先采样 1% 跑通管道 |
| 跨源符号歧义 | Wikidata 锚定 + 人工校验样本 |
| LLM 生成的边不可靠 | 置信度字段 + 人工审核闭环 |
| 量纲/配平实现成本 | 直接用成熟库（SymPy / pint / RDKit） |
