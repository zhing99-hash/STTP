## §1　项目是什么（冷启动）

### 1.1　一句话定位

**STTP**（Science Topology Through Physics）= 把数学公式、物理规律、化学物质与物理世界（元素 / 分子 / 反应 / 单位 / 物理量）连成**一张可推理的知识图谱**，并且**每条边都带可追溯的出处与强度标签**。

### 1.2　它想解决的真问题

通用大模型给出的科学答案是通顺的，但**不告诉你哪一跳是它猜的**。STTP 的做法是：答案必须由图谱检索产生（retrieval-only），每条边附 `verification_level / confidence / source / explicit_or_inferred`，**推断边一律标注并降权**，图上没有就说没有。

### 1.3　四层架构（README 宣称）

```
数据层（MathXiv / PhysicsBabel / ElementKG 2.0 / PubChem / Wikidata / ChEBI / Rhea / NIST）
   ↓ 异构适配器
知识层（NetworkX 本地图；节点 Formula/MathConcept/Symbol/PhysicalQuantity/Element/
       Molecule/Reaction/Unit/Constant/FunctionalGroup；边上带溯源五元组）
   ↓
推理生成层（GNN 链接预测 + LLM 假设 + 符号校验门控：SymPy / pint / RDKit）—— ★ 见 §4.1-A3，此处有冲突
   ↓
交互层（D3/Cytoscape.js + stdlib ThreadingHTTPServer 单机服务）
```

### 2.2　「可红性」—— 我方最重要的自我约束

一条判据如果不能**被证明会变红**，它就不是判据，是装饰。具体做法：

- **负对照**：每个正面判据旁配一条 `NEG-*`，用**真实文件**上的真实改动做反例（改原子量、删函数、篡改哈希），不是合成样本。
- **红探针**：临时副本上注入缺陷 → 断言必须红 → `finally` 还原。
- **非真空自检**：门禁第 `[10/13]` 步注入已知假边，验证不变量不是恒真式。

实测（本轮）：Phase 82 新增的 R62–R65 四条探针，**全部实测变红**（8/0）。

### 2.3　四个代表性顽疾（说明这套仪器真的在抓东西）

| 编号 | 顽疾 | 为什么值得说 |
|---|---|---|
| **D140** | 注册 ≠ 生效 | 同一教训出现 **4 次**：能力在服务端接上了，但另外 4 处自建 registry 的调用方拿不到 ⇒ 等级凭空掉档 |
| **D149** | 判据「自洽」≠「没变差」 | 703 条边从 5 分掉到 1 分，而 G2 断言「5 分且 fidelity≠verified」**照样绿**——因为掉档后它们不再是 5 分。**661 条边凭空掉 4 档，没有任何一处报错** |
| **D146** | 慢仪器本身就是风险源 | 仪器跑 110 秒 → 外部超时 SIGTERM → `finally` 未执行 → 注入残留 → 后续判据在被注毒的文件上跑。110s 优化到 4s 是**安全性修复** |
