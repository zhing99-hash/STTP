# 开发交接记录模板

复制本文件，新建 `YYYYMMDD_助手名_任务主题.md`；不要修改模板本身。请只记录可公开的信息。

## 基本信息

- 时间 / 执行方：
- 用户目标和授权范围：
- 仓库 / 分支 / 起始提交：
- 最终提交、是否推送、远端分支：
- 状态：进行中 / 待复核 / 已完成 / 受阻（写明原因）

## 本次工作

- 变更内容及原因：
- 重要文件和入口（使用仓库相对路径）：
- 数据、接口、版本及兼容性变化：
- 明确保留、排除或未完成的内容：

## 验证与证据

- 原始输入或来源、版本、许可和必要的哈希：
- 使用的方法、工具和版本：
- 测试命令、环境、通过 / 失败 / 跳过数量及原因：
- 独立证据、专家审阅或用户试用情况；未做时明确写明：
- 已知问题、适用范围及反例：

## 下一位接手

- 下一步具体任务及验收标准：
- 依赖、风险、需用户决策事项：
- 相关文档、提交或问题链接：
- 顶尖专家还会补做哪些事：
- 应回到哪些最原始素材核对：
- 推荐采用的具体方法与工具：
- 除双方自检之外，如何独立证明结果：
