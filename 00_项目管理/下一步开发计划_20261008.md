## 三·补·b · A5 轮新增发现（2026-10-08）

A5（元素命名空间去重）施工中又跑出三个真问题，已在同轮修复：

1. **A2 的 GNN 在不同元素之间猜出了 `same_as`**（最严重）
   `gate_check()` 的 Element×Element 分支只判同周期/同族，两者都不满足时返回 `None`，Part A 便**直接采信 GNN 的类型预测**。
   于是产出 `Cl→O`、`N→H`、`H→C` 等 **13 条跨元素符号的 `same_as`**（`same_as` 语义是「同一实体」，跨符号绝不成立）。
   触发原因：`EL:c/h/o`、`BC:el:nitrogen` 挂着 375~670 条 `composed_of` 入边，呈"超级枢纽"形态，嵌入趋同。
   → 清存量 13 条 + `gnn_infer.py` 门控加硬约束（跨符号且既不同周期也不同族 → `REJECTED`）。

2. **`graph_export.py` 在 import 时替换 `sys.stdout`，会让长驻服务全局失联**
   原写法 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, ...)` 有 **GC 关闭底层 fd** 陷阱：旧 wrapper 被回收时连带关掉同一个 buffer，
   此后进程内所有 `print` 抛 `ValueError: I/O operation on closed file`。
   `viz_server.py` 的 `/api/stats` 一旦触发该 import，服务就**对所有请求返回空响应、连访问日志都打不出**。
   → 改用 `stream.reconfigure(...)` 原地改编码。

3. **`/api/stats` 的类型分布与快照对不上**
   统计直接用 `labels[0]`，但 1658 个节点的 labels 是 `["Entity", "Reaction"]`，首标签恒为 `Entity`，
   导致 Reaction/Molecule/Symbol 全被吞成 `Entity`。→ 改用权威 `graph_export.pick_type()`。

## 三·补·c · A4/A9 轮新增发现（2026-10-09）

网络恢复后推进 A4（离线可视化）与 A9（Kuzu 幂等化），施工中又挖出四个真问题：

1. **fcose 布局从来没有真正生效过（依赖链缺失）**
   `cytoscape-fcose.js` 的 UMD 头是 `root["cytoscapeFcose"] = factory(root["coseBase"])`，
   而 `cose-base.js` 又是 `factory(root["layoutBase"])` —— **三级依赖链**。
   页面原先只引了 fcose 一个文件 → `factory(undefined)` 抛错 → 被 `try { cytoscape.use(...) } catch(e) {}` 吞掉
   → **静默退回内置 cose 布局**，功能表面正常、实际从未启用。
   → 修法：按 `layout-base → cose-base → cytoscape-fcose` 顺序本地化并加载；
   A4 测试增加 `fcose_registered === true` 断言作为永久回归守卫。

2. **MathJax 用 CHTML 构建根本无法真离线**
   `tex-mml-chtml.js` 需另拉 30+ 个 woff 字体文件（散在多个子目录），断网时公式渲染不出。
   → 改用 `tex-svg.js`：SVG 输出把字形路径**内嵌进 DOM**，单文件自包含（2.1 MB）。
   且页面原有配置 `svg: { fontCache: 'global' }` 本就只在 SVG 输出下生效 —— 说明原配置与所加载的构建**从一开始就不匹配**。

3. **`viz_server.py` 自身仍在用被项目废弃的 stdout 替换写法**
   第 45–50 行 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, ...)`，正是 A5 轮导致服务
   "端口在监听但对所有请求返回空"的那个模式。→ 改为 `stream.reconfigure(...)` 原地改编码，与项目约定对齐。

4. **A3 测试台缺 `document.write` 桩**
   A4 引入的 CDN 兜底写法在 `vm` 沙箱里抛 `TypeError: document.write is not a function`（真实浏览器无此问题）。

1. **学科标注系统性错误**（三处）：`_NS_SUBJECT` 把 CM/QM/TH/EM 等**物理切片命名空间**误标「数学」、缺 11 个键；11 个 build 脚本把物理/化学符号 domain 硬编码 `math.symbol`（**82 处纠正**）；`biology.*` 落入「跨学科」（归化学）。
2. **13 个符号无任何 `has_symbol` 入边** → 按语义归属补接线边。
3. **42 个 `EK2:rxn:*` 真孤儿**（deg=0）→ 根因是 `elementkg10m_ingest.py` 只要求「有参与物行」而非「**能解析出分子**」；已修源头 + 删孤儿。
4. **CODATA 桥常量「只建节点不建边」**：10 个跨学科桥常量 + `faraday_const` 共 11 个 deg=0（上轮报告文字对、落地缺）→ 补 18 条定义式边 + 6 条单位边。
5. **切片本地元素命名空间与 A5 去重结论漂移**（`EL:*` / `BC:el:*` / `IC:el:*` vs `EK:el:*`）→ `seed_common.BASE_IDS` 与 6 个脚本修源头。
   ⚠ **诚实说明**：这些边在图谱里**并不缺**（A5 已改挂），本轮**没有**"新增 42 条连接"；价值在**消除 seed↔图谱双向漂移**（否则重跑会把重复元素节点重新种回去）。
6. **`MX:math:power_rule` 三节点孤岛** + **`RT:un:c` 把光速常量误标为 Unit** → 补 1 条对齐边、删误标节点、补真实单位 m/s。
7. **类型标签不受控**：`Physical_quantity`×7 / `ElementEntity` / `PhysicsEntity`；`WikidataEntity`（24 个）未登记 `TYPE_PRIORITY`、前端 `TYPE_STYLE` 也缺 → 建 `normalize_labels.py` + 补词表 + 补前端样式。
   **铁证**：`gnn_infer.py:97` 早已在**消费端**打补丁 → 典型「下游补丁替代源头修复」。

### 另发现并修复 2 处**推送基础设施**缺陷（都会导致静默错误）

1. **删除节点静默变成空操作**：`push_element_merge.py` 假设 `delete_nodes` 是字符串列表，而新工具产出 `[{"id":..}]` → 二次包裹后 `MATCH` 落空，**一条没删且不报错**；**更糟的是"残留自检"用同一份错 id，也一起静默通过**。→ 新增 `norm_del_ids()` + **实删数断言**（残留>0 退码 3）。
   **教训：「语句跑完」≠「事情做成」；送出行数不是实删数。**
2. **`apoc.create.addLabels` 只增不减**：用于标签规范化会让云端变成 `[Physical_quantity, PhysicalQuantity]` 与本地分叉。→ 新增 `--set-labels`（`setLabels` 整体替换），**默认行为不变**。

### 本轮新增的方法论（已入长期记忆）

- **改指标口径与改数据必须分开对照**：本轮跨域边 1054→991→869，其中 −185 全部是**删假阳性**（旧口径下 63+122 条同域边被误计为跨域）。不做对照就会得出「修复让北极星变差」的**完全错误**结论。
- **种子不是权威**：种子里存着被后续真实化取代的旧值（`TH:pq:gas_const` 种子 `8.314` vs CODATA 2022 `8.314462618`）。「seed → 权威图」的回灌必须有**权威性守卫**（溯源键不许改写 / 外部权威源的载荷键不许覆盖），实测拦下 **9 处越权覆盖**。
- **自检若与被检对象共用同一份（错的）输入，会一起静默通过。**
- **文档宣称的与数据实际落地的要分别核验**（「新增 10 个桥常量」文字无误，但一条边都没建）。
