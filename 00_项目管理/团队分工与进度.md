## 三、关键决策记录
- **范围策略**：MVP-first（先可控规模，后科研级扩展）
- **原型图库**：Phase 1 用 NetworkX（轻量、可出图）；Phase 2 生产用 Neo4j，开发态用 Kuzu（嵌入式 Cypher，无需 Java）做验证
- **置信度字段**：所有推断类边必须带 `confidence` 与 `explicit_or_inferred`，不可靠边降权
- **对齐层**：Wikidata 作为跨源概念锚定与去重真理源
- **超大源处理**：math-graph / ReactionAtlas / Wikidata 一律流式/惰性 + 先 1% 采样跑通（零 OOM）
- **全局节点 id**：`<source>:<local_id>`，仅 Align 后按 `wikidata_qid` 合并
- **可信性优先于规模（2026-10-10 · Phase 27）**：任何"推断边"必须声明**验证范围**（`verification_scope`）；
  `verified` **不可作单一布尔**（铁律 #19）。已坐实的错误模式**冻结为反例集**（`06_PoC/frozen_gate.py`），
  与 `connectivity_audit.py` **并列**为门禁；门禁因缺依赖降级须记 SKIP（不可当 PASS）。
- **定位 A · 研究原型（收敛版）（2026-10-10 老板裁定）**：北极星由「跨域边计数 / 学科占比」
  改为 **「固定任务集上，跨域结论正确且证据可追溯的比例」** —— 先做可信，再谈规模。
- **分层可信 + 北极星仪器化（2026-10-10 · Phase 28）**：`verified` 落地为 **7 档受控词表 + `verification_scope` + `verifier`**，
  口径 `verified_strict = level ≥ rule_checked`；**分级原则「证据优先于提出者」**（先做与提出者无关的确定性复算）。
  北极星显式化为 **8 任务族 T1–T8**（`06_PoC/task_trust_audit.py`），**成对读**覆盖率 + 达标率。
- **「改正派生字段 ≠ 撤回原始断言」（2026-10-10 · Phase 28）**：断言被推翻时须**同时撤回原始字段**并留痕
