## 〇、一句话

STTP 是一个**跨学科公式知识图谱**：把物理方程、化学反应、分子结构、数学概念、物理量与单位、文献引用
放进**同一张图**，并对**每一类关系**都回答同一个问题 ——「这条关系凭什么可信」。
它的产出不是"一张大图"，而是**一套可复算的可信度账本 + 一台能验出自己问题的仪器**。

## 一、项目是什么

### 1.1 定位（**收敛版 A 研究原型，不做产品化**）

- 目标读者是**外部评审者**（GPT6 / codex / 人类专家），不是终端用户。
- 因此项目对自己的要求偏"**可核验**"而非"好用"：**宁可如实说"这里没验过"，也不给一个漂亮但没证据的结论**。
- 已知的、已被承认的边界统一收在 `PROJECT_DEVELOPMENT_GUIDE.md` §0.3（12 个小节，Phase 43→55）。
  **重复报告这些边界不算新发现**（§0.2 明文约定）。

### 3.1 前端（用户可见）【实测 · `graph_view.html` + `js/`】

三栏布局：左=查询面板与图例 ｜ 中=画布 ｜ 右=详情面板；底栏=五态状态行 + 路径高亮。

| 功能 | 入口 | 说明 |
|---|---|---|
| **任务式首屏** | 启动即显示（4 张示例卡） | 问题 → 候选（≤5）→ 确认实体 → 生成局部图 |
| 示例卡 | ①吉布斯自由能与熵（path，预填 3 跳）②量纲是否一致 ③单位与相关公式 ④分子组成 | 每题都自带「不可达就如实说不可达」的注解 |
| 全局搜索 | 顶栏 | 歧义候选**先列出再选**（同名实体来自不同来源） |
| 概览 | 顶栏「概览」 | **聚合元图**（学科 × 类型），替代"全图浏览" |
| 图交互 | 画布左上角 | 返回 / 展开邻居 / 适应 / 重置会话 / 5 种布局（fcose·同心圆·层次·环形·网格） |
| 详情面板 | 点节点或边 | 含**证据卡**（Claim/Evidence）、字节忠实度、stale 提示、公式**年代**与**元数据依据** |
| 路径高亮 | 底栏 | 起点/终点（可取选中）/ 交换 / 高亮 / 清除；超时与无路径**如实区分** |
| 导出 | 顶栏 | PNG（含水印）/ SVG / JSON（子图+证据+snapshot_id） |
| 五态状态 | 底栏 | ok / no_result / truncated / timeout / error，**颜色+图标+文字三重编码** |
| 运行模式 | 顶栏徽标 | `live`（后端在）/ `bundle`（静态回退）/ `offline` |
| 响应式 | — | 断点 375 / 768 / 1024 / 1440 |
