关键设计取舍：

- **边的选取**：`/api/path` 只返回节点 id 序列，不含边。同一对节点间可能有多条边（含正反向），故用 `pickEdge()` 取「同向优先 + 置信度最高」的那条，避免高亮错边。
- **跨域判定口径**：沿用 viz 既有的 `subject` 字段（数学/物理/化学/跨学科）。`跨学科` 视为**哨兵值**，不参与跨域判定——否则 4 个未定学科的节点会凭空制造「跨域」。
- **排序**：候选路径按跳数升序，默认高亮最短那条；每张卡片单独显示自己的跨域次数。

### 2.2 顺带修掉的两个真问题

做 A3 时在真实数据上跑出两个既有缺陷，都是**正确性问题**，一并修了。

#### 缺陷 A · `subject_of` 把物理量误标成「数学」

- **现象**：`PQ:energy` / `PQ:mass` / `PQ:c` / `PQ:force` / `PQ:accel` / `PQ:vel` / `PQ:ke` 这 7 个物理量节点，`domain` 属性为空。
- **根因**：`06_PoC/graph_export.py` 的 `subject_of()` 结尾是 `return "跨学科" if d else "数学"` —— **domain 为空时兜底成「数学」**。物理量因此被涂成数学色，直接污染 A3 的跨域判定（`化学 → 物理量` 会显示成 `化学 → 数学`）。
- **修复**：`subject_of(domain, node_id="")` 增加第二个参数，domain 为空时按 id 命名空间兜底（`PQ`/`PB` → 物理，`EL`/`EK`/`EK2`/`IC`/`BC` → 化学）；**未知前缀仍保持旧的「数学」行为**，把改动面压到最小。调用点同步传入节点 id。
- **影响面（实测 diff）**：仅 **10 个节点**，且全是纠正——

  | 节点 | 旧 | 新 |
  | --- | --- | --- |
  | `PQ:energy` `PQ:mass` `PQ:c` `PQ:force` `PQ:accel` `PQ:vel` `PQ:ke` | 数学 | **物理** |
  | `EL:h` `EL:c` `EL:o` | 数学 | **化学** |

  学科分布：`化学 1771→1774 · 数学 185→175 · 物理 5168→5175 · 跨学科 4`（不变）。边集合**逐字节一致**。

#### 缺陷 B · 边 id 撞号导致 3 条边被静默折叠

- **现象**：`/api/stats` 报 36504 边，而快照里是 36507 条。
- **根因**：边 id 约定为 `type|source|target`，**不含 `kind`**。同一 (type, source, target) 上存在不同 kind 的边时 id 撞号：

  | 撞号 id | 两条边 |
  | --- | --- |
  | `derived_from\|MX:thm:gauss_bonnet\|MX:thm:riemann_curvature` | `explicit_citation`（mathxiv 证据）／ `llm_inferred`（HYPO-GRAPH-001） |
  | `dimensionally_consistent\|PQ:energy\|PQ:mass` | `mass_energy`（curated_seed）／ `real`（PhysicsBabel） |
  | `dimensionally_consistent\|PQ:force\|PQ:mass` | `force_mass`（curated_seed）／ `real`（PhysicsBabel） |

- **后果**：NetworkX `MultiDiGraph.add_edge(key=id)` 把撞号边**静默折叠**（36507 → 36504）；**Cytoscape.js 更是要求元素 id 唯一**，重复 id 会造成渲染异常。
- **修复（三处）**：
  1. `graph_export.py` 新增 `uniquify_edge_ids()`，在 `build_graph_data()` 出快照前统一兜底去重，并把修正条数写进 `meta.edge_id_collisions_fixed`；同时新增节点 id 重复告警。
  2. `export_normalized.py`（Aura → normalized.json 的导出器）：fallback id 改为 `type|source|target|kind`，并在写文件前统一兜底去重。
  3. 对存量 `normalized.json` 打一次去重补丁（撞号者追加 `|kind`）。
- **结果**：`/api/stats` 恢复 **36507** 边（+3）；phase14 快照 **36507 / 36507 id 全唯一**，节点 id 重复 0。

## 五、使用说明

1. 启动服务：`bash sttp.sh viz`（**必须走 `sttp.sh`**，它会 `source env.sh` 注入 `GRAPH_DATA_FILE=06_PoC/graph_data_phase14.json`；
   直接 `python 06_PoC/viz_server.py` 会退回到 42 KB 的陈旧 `graph_data.json`）。
2. 浏览器打开 `http://127.0.0.1:8765/`。
3. 挑两个端点：**Shift+点击**节点设为起点，**Alt+点击**设为终点；或选中节点后点「↓取选中为起点 / ↓取选中为终点」。
4. 点「高亮路径」→ 底栏出现候选路径卡片，默认高亮最短的一条；点任意卡片可切换。
5. 图例：青/红/金环 = 起点/终点/中间节点；金色实线 = 同域跳；品红粗线 = **跨域跳**（学科发生切换）。
