## 二、Phase 5.A — Wikidata 实时对齐

**适配器**：`09_科研扩展/5A_wikidata/wikidata_adapter.py`
- `WikidataAdapter` 类：wbsearch / get_qid / get_relations / classify_domain
- 带重试、本地缓存（`data/wikidata_cache.json`，39 SPARQL + 21 wbsearch 缓存命中）
- 排歧义：过滤 `wd:Q4167836`（Wikimedia 消歧义页）

**实测结果**（`same_as_edges.json`）：
- 对现有 36 节点中 19 个找到 Wikidata QID
- 28 SPARQL 查询成功 / 10 失败（网络抖动，已用 wbsearch 兜底）
- 样例：
  - `MX:thm:gauss_bonnet` → `WD:Q742833`（Gauss–Bonnet theorem）
  - `MX:def:manifold` → `WD:Q3552958`
  - `MX:chem:co2` → `WD:Q1997`（carbon dioxide）
  - `MX:phy:energy` → `WD:Q11379`
- 全部置信度 0.7（wbsearch 方法学基线）

**价值**：把孤立的领域图谱锚定到全球最大开放知识库，为后续跨语言、跨领域推理提供桥接。

## 三、Phase 5.B — GNN 依赖推断

**模型**：`09_科研扩展/5B_gnn/gnn_model.py`（纯 torch，禁用 torch_geometric）
- 2 层 GraphSAGE，消息传递 + 邻居聚合手写
- 节点特征 29 维：类型 one-hot(12) + 标签 hash 嵌入(16) + 归一化度数(1)
- 链接预测：训练正样本 = 现有 52 边，负样本 = 随机采样非边
- 推断用 L2 归一化 cosine（解决 raw dot 导致 sigmoid 饱和成常数的问题）

**实测结果**（`phase5_gnn_edges.json`）：
- 训练：loss 0.7285 → **0.3713**（CPU 2.6s），acc 0.955，checkpoint 已存
- 推断：586 候选非边打分，输出 **20 条**，置信度 0.6940–0.7311，**全部互异**
- 语义合理样例：`MX:thm:gauss_bonnet → MX:sym:rho_alpha`（has_symbol，rank 7）

**价值**：证明"用图神经网络在稀疏数学图谱上发现隐含依赖"方法学可行，为生产级 GNN 训练（更大图、更多 epoch）铺路。

## 四、Phase 5.C — 跨源实体对齐

**算法**：`09_科研扩展/5C_entity_linker/entity_linker.py`
- 三相似度：标签（rapidfuzz token_sort）、符号（精确）、定义（TF-IDF 余弦）
- 加权总分 `0.4*label + 0.1*symbol + 0.3*definition + 0.2*domain`
- 阈值 0.7 标 high-confidence；`matched_by` 记录命中特征（可解释）

**实测结果**（`aligned_candidates.json`）：
- 模拟多源节点池 68 个（MX 36 / MG 4 / PB 3 / EK 7 / WD 18）
- 60 条候选，**7 条高置信 ≥0.7**
- 样例：`MX:sym:pi`↔`wd:Q_pi`(0.97)、`MX:def:manifold`↔`wd:Q_manifold`(0.87)、`MX:chem:co2`↔`ek:molecule:CO2`(0.80)

**价值**：科研级数据融合的核心组件，可独立接入 Phase 5.A 的真实 Wikidata 查询（README §5 已写明契约）。

## 八、已知约束与后续

**沙箱约束（不可改）**：
1. 无 Java/Docker → 真实 Neo4j 跑不了；Aura / Kuzu / NetworkX 三条路线并存
2. 真实大库（ElementKG 100+GB / ReactionAtlas 26GB / Wikidata 130GB dump）沙箱下不去 → 用 SPARQL API + 合成样本
3. torch 仅 CPU → GNN 训练规模受限，已证明方法学可行
4. Wikidata SPARQL 有礼貌节流（≥3s/查询），部分查询超时（已用 wbsearch 兜底）

**建议后续**：
- A. 把 Phase 5 图（98 边）推送到 Aura（复用 `load_neo4j.py` + `neo4j+ssc://`）
- B. GNN 真实训练：等 ElementKG 真实数据灌入后，在更大图上训练
- C. 把 5.A 的 19 个 Wikidata QID 作为种子，扩展跨语言标签
- D. CDN 离线化（Cytoscape/MathJax 本地 vendored）以便无网环境预览
