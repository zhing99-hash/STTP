  1. 完整交付 **Neo4j-ready** 产物（导入 CSV + `load.cypher` + 驱动加载器），在有 JVM 的环境可一键落地。

## 四、真实执行验证（实跑证据）
| 验证项 | 命令 | 结果 |
|---|---|---|
| ETL（MathXiv） | `python etl_pipeline.py` | ✅ 22 节点 / 44 边 |
| ETL（全部源） | `python etl_pipeline.py --source all` | ✅ 40 节点 / 60 边（MG 因缺库优雅跳过） |
| 查询层(NetworkX) | `python queries.py --backend nx` | ✅ 6 类查询全对（含 gauss_bonnet→manifold 5 条路径） |
| **图库真实 Cypher** | `python load_kuzu_demo.py` | ✅ Q1 22 节点 / Q2 44 边 / Q3 定理 / Q4 低置信推断边(conf=0.79) / Q5 两跳路径 / Q6 类型统计 |
| Neo4j 加载器 | `python load_neo4j.py` | ✅ 缺驱动→友好提示 + exit 0（非致命） |

**关键约定**：全局 id `<source>:<local_id>`（MX/MG/PB/EK/WD）；所有边强制带 `confidence` / `explicit_or_inferred` / `source`；`definition_bank → Symbol 节点 + defines 边`；推断边（`llm_inferred`）自动降权并保留原始 `kind`。
