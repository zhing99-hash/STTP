## 一、为什么做这一轮

复评给出的三组指标中，第二组长期缺位：

| 指标组 | 位置 | 状态 |
|---|---|---|
| 数据与验证覆盖 | `task_trust_audit.py`（北极星 T1–T8 / T9 / T9-i） | 已有 |
| **科学任务表现** | **本轮新增 `12_评测/`** | ★ 本轮补齐 |
| 新候选研究收益 | GNN 盲评 | 后续 |

复评原话：「现在的 T1–T8 是按边类型选择任务族，再对 `verification_level` 设阈值……
**没有独立答案、任务执行结果和人工判分，不能推出「任务结论正确」**」。
本轮把「专题任务」变成**可检查、可复现、可失败**的评测件，并把三组指标**分列**。

## 二、交付物（新增目录 `12_评测/`）

| 文件 | 作用 |
|---|---|
| `build_tasks.py` | 定义 **40 题冻结任务集**（热力学-化学平衡-数学方法）+ 确定性分层切分；产出 `tasks.json` |
| `tasks.json`（`sttp-eval-tasks/v1`） | 冻结任务集：题干 / 条件 / 期望答案或拒答 / 判分标准 / **独立权威来源** / 切分 |
| `eval_runner.py` | **规则基线**运行器：只读规范图 + 真值表；逐题作答/拒答；产出 `eval_report.json`（`sttp-eval-report/v1`） |
| `eval_report.json` | 逐题结果 + 逐类 / 逐切分 / 困难反例汇总 + Wilson 95% CI |
| `README.md` | 第三人使用指南 + 诚实边界 |

接入：`bash sttp.sh eval [--split test]` → 构建 + 评测 + 非真空自检，一步跑通（rc=0）。

## 三、任务集构成（40 题 · 5 类 + 6 型困难反例）

| 类别 | 题数 | dev / test | 说明 |
|---|---|---|---|
| 数据查证 `data_verification` | 10 | 6 / 4 | 常量与元素真值 vs CODATA/IUPAC |
| 单位与状态 `unit_state` | 8 | 5 / 3 | 量纲齐次、无量纲性、同量纲异义 |
| 有限数值 `numeric` | 8 | 4 / 4 | K↔ΔG°、pKa、Henderson、ΔG=ΔH−TΔS、ΔG=ΔG°+RT ln Q |
| 方法选择 `method_selection` | 6 | 4 / 2 | 选 K 还是 Q、选哪个关系式、算子桥类型 |
| 条件不足拒答 `refusal` | 8 | 4 / 4 | 缺条件必须拒答 |
| **合计** | **40** | **23 / 17** | 基本 27 / 困难 13 |

**6 型困难反例全覆盖**（复评指定）：
温度缺失 · 物相混淆 · 质子化态不一致 · 同分子式异构体 · 对数定义域 · 量纲相同但物理意义不同。

### 答案独立性（复评的硬要求）

每题 `expected` 锚定**外部权威源**，**不由被测图生成**：

- `DV-*` → NIST CODATA 2018 / SI 2019 / IUPAC 2021
- `NM-*` → 标准热力学关系（ΔG°=−RT ln K、ΔG=ΔG°+RT ln Q、ΔG°=ΔH°−TΔS°）
- `US-*` → 量纲分析（Buckingham π）
- `MS-*` → IUPAC 定义 / 复评 R04（关系名须与检查命题一致）

> **诚实边界**：做到了「不由被测系统生成」，但复评要求的「**学科人员已审**」**尚未满足** ——
> 任务与答案由本轮编写，权威源为外部标准。见 §六。

### 5.5 非真空自检（铁律 #14 / #38）

`eval_runner.py --selfcheck`：对 40 题逐题注入确定性扰动（数值 ×2+1 / 布尔取反 /
选项加后缀 / 把拒答改成作答），断言判分器**真的判非通过** → **40/40 全部检出**，rc=0。
即：**100% 不是「哑判分器」造出来的**。

**实测旁证**：本轮首次运行时，判分器**当场抓出 2 个真缺陷**——
`US-07` 误拒（单位串与量纲串被同一解析器误当一套语法）、
`US-08` 答错（未区分钟摩量差异）。二者均**修在源头**后复跑通过。
这既证明判分器有牙，也说明**没有为了好看而调判分**。

## 六、诚实边界（**必读 · 本轮最重要的部分**）

1. **任务与规则同源**：任务集与基线规则由同一轮编写，`test` 切分是**准留出**
   （quasi-held-out），**不是严格独立留出**。基线修正后重跑通过，**不能**当作泛化证据。
2. **100% 是自洽性结果**：它只说明「规则基线与其自建冻结集自洽」，**不构成**
   跨域任务正确率的一般证明；**不可**与北极星 99.6% 直接比较（口径完全不同：
   那是数据覆盖 / 边标签，这是任务级作答）。
3. **学科人员外部审查待进行**：复评要求「任务及答案应由学科人员审查」——**未满足**。
   本轮只做到「答案不由被测系统生成」。
4. **样本小**：40 题，CI 下界仅 ~91%；不代表全学科可靠性。
5. **候选空间有限**：基线只用图与两真值表；未用到 LLM、未用网络。这既是「可复现」的
   保证，也意味着它**测不出**超出该候选空间的能力。

> 复评原话：「有限专题任务正确完成率至少 90%……**这是建议的验收目标，不是项目目前
> 已达到的数字，也不是全学科可靠性的证明**。」本轮结果须在此框架下理解。

## 八、复现

```bash
PY="${STTP_PYTHON:-python}"
"$PY" 12_评测/build_tasks.py --check          # 任务集校验（确定性）
"$PY" 12_评测/eval_runner.py --json 12_评测/eval_report.json
"$PY" 12_评测/eval_runner.py --strict         # 困难反例零误判 → rc=0
"$PY" 12_评测/eval_runner.py --selfcheck      # 判分器有牙 → rc=0
# 或一步：
bash sttp.sh eval                             # rc=0
```

环境：系统 Python 3.11.9（`$STTP_PYTHON`）；无网络依赖；产物 `tasks.json` /
`eval_report.json` 均确定性（同输入同输出）。

## 九、本轮新增铁律

**#54 评测集必须能失败**：一个「全对」的评测若没有**非真空自检**（注入扰动须判非通过）
与**修订留痕**（首跑抓到的真缺陷须记录、修在源头、不得调判分迁就），
则 100% 不构成任何证据。自建集上的自洽性 ≠ 泛化能力。
