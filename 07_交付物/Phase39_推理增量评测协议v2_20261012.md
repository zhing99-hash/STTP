# Phase 39 · 推理增量评测协议 v2（第 29 轮）

> 对应 GPT6 复评「新候选研究收益」条目（`07_交付物/外部评审/STTP_复评与Apache2.0许可意见_20261011.md` §GNN）。
> 一句话结论：**在版本化规范数据上、以标准全量 filtered MRR 口径，GNN 未提供超越「schema 规则 + 度先验」的稳定增量 —— 保留规则方案。**

---

## 一、为什么做这一轮

复评对旧 GNN 评测提出五条可核实指摘（原文要点）：

| 编号 | 指摘 | 本轮对应 |
|---|---|---|
| C1 | 切分在**每种关系内部独立**进行 ⇒ 同一实体对可通过**另一种关系**同时出现在训练邻接（合成数据实测 **20/20**）。不足以支撑「从未见过的实体对」的更强说法 | 新增 **P1 RHC / P2 EPD** 两级协议 + **跨关系泄漏诊断** |
| C2 | MRR 仍是每条正例抽 **250 个全局随机负例**（有重复采样、未用同类型候选池）⇒ 既非全实体排名，也不可与标准**全量 filtered MRR** 比较 | 改为**全量** filtered MRR（候选=全实体）+ **类型一致困难负例**档；显式报告候选空间/过滤规则/种子 |
| C3 | 缺少**规则检索 / 相似度 / 简单图方法基线** ⇒ 无法判断 GNN 是否提供增量 | 新增 4 类基线（CN/AA/RA、特征相似度、规则检索）+ 随机下界，**同一测试集/候选空间/过滤规则**下对照 |
| C4 | 训练入口读**展示层投影**（`graph_data_phase12/13.json`）⇒ 研究样本应来自**版本化规范数据** | 数据源改为 `06_PoC/etl/normalized.json`，**记录 sha256 钉死版本** |
| C5 | 历史 MRR 不能因切分源码修好就自动成为新协议下的结果 ⇒ 需重跑 | 全部指标本轮**重算**，不沿用历史值 |

## 二、协议与参数（可复现）

**数据源**：`06_PoC/etl/normalized.json`
　`sha256 = 5adf7f0dce097c6ae8fc6f77bcfa1c653d01b7d4aebb49cc96c952efad057cf0`
　9657 节点 / 48712 边 · 18 个关系（样本 ≥ 30）· 15 节点类型 · 4 学科

**切分（P1 关系留出补全）**
- 每关系按**无向对**整组留出 10%，上限 100 组（防止 (a,b) 训练 / (b,a) 测试的反向泄漏）
- 训练邻接、结构特征、schema 掩码**一律仅用训练边**构建
- 随机种子 `seed=0`（切分）；训练种子另报（`0/1/2`）

**候选空间与过滤规则（两档并报）**
| 档位 | 候选空间 | 过滤规则 |
|---|---|---|
| 全实体（headline） | 全部 9657 实体 | 排除该关系下 `(r, fixed)` 的**全部已知真尾**（filtered）后排名 |
| 类型一致（困难负例） | 该关系**模态尾类型**的实体全集 | 同上 + 类型约束 |

**P2 实体对留出发现（EPD）**
- `EPD1（对级留出）`：测试对在**训练子图内两端点无任何直连**（跨关系）→ 890 条
- `EPD2（严格非传导）`：EPD1 中再要求**无共同邻居** → 546 条
- 邻域诊断（防「空邻域假象」）：EPD1 两端点训练度 40.18 / 428.33、平均共同邻居 **4.33**、空邻域仅 18 对（2.0%）⇒ 「非传导」是结构事实

## 四、结论

1. **主结论（负结果）**：当前 STTP 图上，GNN（ComplEx + 2 层稀疏 GCN，含 schema 掩码解码）在标准全量 filtered MRR 口径下**显著劣于**「schema 规则 + 度先验」基线（Δ=−0.061，CI 不含 0）；取最佳种子亦未反超。**建议保留规则方案**，与复评预案一致（「如果模型无增益就保留规则方案」）。
2. **P2 发现任务**：在真正「未见过的实体对」（含严格非传导）上，规则基线同样领先（0.2052 vs 0.1395 / 0.1671 vs 0.1437）。
3. **跨关系泄漏**：本图为 **3.6%（33/923）**，远低于复评在**合成数据**上测得的 20/20 —— 合成数据的泄漏是构造使然，不能外推为真实图比例（复评原文亦如此声明）。本图泄漏主要来自 `same_period`/`same_family` 等结构关系对。
4. **GNN 不稳定**：结果对训练种子敏感（跨度 0.057），其波动量与「增量」同量级 ⇒ **不能据单次运行声称增量**。

## 五、附带修复（本轮实测抓出）

1. **可复现性缺陷（GNN 非确定）**：CPU 稀疏 `mm` 的多线程归约使**同 seed 两次运行 MRR 不一致**（实测 0.1064 vs 0.1069）。修复：`torch.set_num_threads(1)` + `use_deterministic_algorithms(True, warn_only=True)` ⇒ 两次运行**逐位一致**。**新铁律 #56**。
2. **诊断判据假自洽（adj 键混用）**：`adj` 以**字符串节点 id** 建键，泄漏诊断/EPD 却用**整数 idx** 查 ⇒ 全部 miss，伪造出「**0% 泄漏 + 100% 非传导**」两个**互相自洽的假信号**。由新增的「EPD 邻域诊断」（暴露空邻域 443/443）发现。**新铁律 #55**：结构诊断必须同时报告**规模/非空性**，否则 `0` 分不清「真为 0」与「没查到」。
3. 同轮加入**判据非真空自检**：合成「两关系共享同一实体对」的小图，断言泄漏诊断**能报出**泄漏、无泄漏时**报 0**（`PASS`）。

## 七、诚实边界

- 任务/规则/评测器**同源开发**；`test` 为准留出，非严格独立留出。
- 单图、单数据集；结论**限定于当前样本、当前访问路径、当前规则**，不外推为「GNN 无用」的普遍结论。
- GNN 仅一种架构（ComplEx+GCN）与一套超参；未做早停/验证集/超参搜索 —— 不能排除「更强配置有增益」，但**当前证据不支持**。
- 「取最佳种子略超」类结论须警惕**选择性报告**：本报告以**均值与范围**为主，不以最佳种子作结论。
