## 2 · 本轮核心洞察：**人工策划 / 来源断言，同样是「从未被检验过的断言」**

第 20 轮（Phase 30）建立了**「证据优先于提出者」**原则 —— 但它**只对 GNN/LLM 边执行**：
R1/R2 写在 **delta 生成器**里，判级模型 `verification_model` 里**没有**对应规则。

于是出现了一个结构性问题：

> **门禁会红，但判级模型没有规则可撤** —— 两边对同一批边给出不同结论。
> 首次 `apply_delta` 后门禁即 FAIL 1（`semantic_target_present` 报 3 条符号缺失）。

**修法**：把 A11 从「`derived_from` 专用」**推广为「模型产物语义边通用反驳」**，
并与门禁 `model_semantic_target_present` **共用同一谓词** → **构造上不可能分歧**。

这是铁律 #33 的又一实例：**每引入一个新维度，先问「这里有没有从未被检验过的断言」。**
本轮一口气打开了四个此前**从未被检验**的维度。

## 3 · 第一步：关闭命名缺口（`dimension_table.ALIAS` +22 条）

| 族 | 别名 → 规范名 |
|---|---|
| **电磁** | `electric_charge→charge`、`electric_current→current`、`electric_field→efield`、`magnetic_field→bfield`、`vacuum_permittivity→permittivity`、`vacuum_permeability→permeability`、`electromotive_force→voltage`、`magnetic_flux→mag_flux` |
| **量子/相对论** | `planck_constant→planck`、`reduced_planck_constant→planck`、`wavelength→length`、`proper_time→time`、`speed_of_light→light_speed` |
| **统计** | `boltzmann_constant→boltzmann`、`statistical_entropy→entropy` |
| **力学/热学** | `gravitational_constant→grav_const`、`amount_of_substance→amount`、`radius/focal_length/object_distance/image_distance→length` |
| **化学热力学** | `gibbs_free_energy→energy` |
| **光度** | `lum_intensity→luminous_intensity` |

**收录原则（宁缺勿滥，铁律 #28）**：只收「**语义确定无疑的同义命名 / 规范译名**」，
不含任何需要物理推理才能确定的映射；每条都在反例集里配**正对照**。
本轮**主动不建**：`luminance` / `illuminance`（需派生式）、`lorentz_factor`（依赖速度，非量纲常量）。

> ⚠ 一处实现教训：曾把 `"lorentz_factor": None` 写进 ALIAS 表表示「不建」——
> **这破坏了 `canon()` 的返回值约定**（返回 `None` 键）。已删除：**「不建」应靠「缺席」表达**。

**效果**：`T3` 一次从 **56.4% 跃到 80.9%**；同时**新暴露出 8 条量纲互斥的假边**。

## 5 · 撤回 48 条：三类可被确定性反驳的假边

| 规则 | 类型 | 判据 | 条数 | 来源 |

| | | **合计** | **48** | |

### 5.1 R6 的 39 条：两类典型塌缩

1. **`derived_from` 抽象塌缩（36 条）**：`theorem→definition`、`lemma→lemma`、`definition→(a+b)²`、
   `\nabla→R`、`K→\chi(M)` —— 都是**类型词/单个字母**之间的互指，源表达式里根本没有目标标识。
2. **`has_symbol` 同名碰撞（3 条）**：`C→sin²θ+cos²θ=1`、`C→unit circle`、`n→(a+b)²`
   —— `C`（碳元素/常数）与数学对象的 `C` 无关。

> 逐条审为 **GNN 噪声**，撤销是可靠的（sound）。

### 5.2 ★ R8 的 1 条 —— **第 6 条策划数据自身的错误**

| 边 | 记录量纲 | 应然 |
|---|---|---|
| `Electric field --has_unit--> volt` | 电场 = **MLT⁻³I⁻¹** | 电场单位应为 **V/m**（= MLT⁻³I⁻¹），**不是 V**（ML²T⁻³I⁻¹） |

这条**不是模型猜的**，是**策划层**写进去的（`old_level: source_asserted`、`old_scope: manual_curation`），
此前**从未被任何门禁检查过**。第 20 轮抓出 5 条同类错误（`力→kg`/`动量→N`/`角动量→J`/`冲量→N`/`作用量→eV`），
**本条是第 6 条**，且与 R7 的同族错误**互为佐证**：

- `Electric field --dimensionally_consistent--> Electromotive force`（R7 撤）——
  **同一个「把电场当成电压/电动势」的根因**，在「单位」和「量—量」两个维度各暴露一次。

### 5.3 R7 的 8 条

除上面 1 条外，其余 7 条是 `Speed of light` / `planck` / `thermal_diff` / `concentration` /
`grav_const` / `molar_mass` / `lum_intensity` 之间的**任意配对**
（如 `thermal_diff --dimensionally_consistent--> Speed of light`）—— 典型 GNN 噪声。

> **规模变化：9657 / 48760 → 9657 / 48712（−48）。**

### 8.1 ★ 两个仪器缺陷（本轮修好）

**(a) 「空字典是假值」导致断言静默变为 SKIP。**
两条新反例用 `{}`（无参数）作配置 → `scan.get("...")` 返回 `{}`（假值）→ 直接落到
`return "SKIP", "未知 scan"`。**而 SKIP 在门禁里等于「没验」，却很容易被读成「没事」**（铁律 #20）。
→ 改为**成员判定** `if "xxx" in scan:`，对 `{}` / `true` 均健壮。

**(b) 「门禁会红，判级模型没有规则可撤」** → 见 §2，已由 A11 推广修复。

### 8.2 ★ 非真空自检（新增脚本 `06_PoC/_gate_selfcheck_phase31.py`）

> **一条永远不会红的断言不是断言**（铁律 #14）。`PASS` 只说明「当前没红」，
> 不说明「它有能力红」。必须**注入已知缺陷**验证。

方法：**不改门禁代码**，直接 `run_case(case, mutated_graph)` 喂入**内存中注入了一条假边**的图。

```
== 0) 正对照：未注入的原图必须全部 PASS ==
✅ baseline(n) / (o) / (p)                     PASS
== 2) 注入 GNN 假 has_symbol（目标符号缺席）→ FAIL ==
✅ got=FAIL   可判定 9 条，目标缺席 1 条：[('has_symbol','MX:def:manifold','T_p M')]
== 3) 注入 scope=symbol_expr_recompute 但源无符号 → FAIL ==
✅ got=FAIL   symbol_expr_recompute 197 条（需≥196），无证据 1 条
== 4) 注入量纲互斥的假 dimensionally_consistent → FAIL ==
✅ got=FAIL   可判定 39 条，量纲互斥 1 条：[('Energy','Mass',None)]
汇总：✅ 3 条不变量全部**可红** —— 非真空，门禁有效
```

**门禁终态：`PASS 67 / FAIL 0 / SKIP 0`。**

## 11 · 本轮新增/固化的教训（候选铁律）

| # | 教训 |
|---|---|
| **36** | **「被信任」不等于「被验证」**：人工策划 / 来源断言的边同样是「从未被检验过的断言」。第 20 轮的「证据优先于提出者」**只写在 delta 生成器里**，判级模型里没有 → **门禁会红、模型撤不掉**。**规则必须在「判级」与「门禁」两处同源**。 |
| **37** | **空字典是假值**：`scan.get(key)` 在配置项为 `{}` 时返回假值 → 断言**静默退化为 SKIP**。凡「配置项可以无参数」的开关，一律用 **`in` 成员判定**。**SKIP 比 FAIL 更危险**（FAIL 有人查，SKIP 无人看）。 |
| **38** | **`PASS` 只说明「当前没红」，不说明「有能力红」**：新断言必须做**注入式非真空自检**（正对照 PASS + 注入缺陷 FAIL），否则它就是 SKIP 的伪装。 |
| **39** | **命名缺口是会「架空验证器」的**：`dim_of()→None` 不是「没数据」，而是让**早已写好的复算静默退化为不可判定**。**先修命名，再谈复算** —— 一次扩表，T3 就涨 24 个百分点。 |
| **40** | **同源口径才算数**：统计跨域边时若用「边自带的 `subject`」而非**北极星仪器同源**的 `graph_export.subject_of(props.domain)`，会得到 13 而非 15 —— **口径不同源的比较会给出错误结论**。 |
