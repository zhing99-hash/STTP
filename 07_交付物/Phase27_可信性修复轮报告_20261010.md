## 2 · P0-1 · PhysicsBabel「方程齐次」被误写为「两量量纲一致」

**根因**：`physicsbabel_ingest.py` 取方程 `keys` 的**前两个参与量**建 `dimensionally_consistent` + `verified=True`，
**从未比对两者量纲**。但 PhysicsBabel 的 `exponents` 是**方程级齐次系数**（`∏Qᵢ^expᵢ = 无量纲`），
"整式齐次" 与 "两量量纲一致" 是**两个不同命题**。主图沉淀 **1130 条**此类边（占总 1200 条的 94%）。

**修复（源头 + 基础设施）**
1. **新建 `11_真实数据/dimension_table.py`** —— 由 `exponents` **消元反解**出每个物理量的真量纲向量。
   这是量纲分析的标准逆问题，无外部依赖、可复现。实测解出 59 个量，**物理全部正确**：
   `force=MLT⁻²`、`energy=ML²T⁻²`、`voltage=ML²T⁻³I⁻¹`、`planck=ML²T⁻¹`、`permittivity=M⁻¹L⁻³T⁴I²`、
   `grav_const=L³M⁻¹T⁻²` ……（含 3 个光学量因缺 J 基未解 → **宁缺勿滥，不建边**）
2. **改 `physicsbabel_ingest.py`**：删除"前两量"逻辑；`dimensionally_consistent` **仅在量纲严格相等时**建立；
   方程齐次性改记 **Formula 节点属性** `dim_homogeneous / dim_scope / dim_verified_by`。
3. **改 `gnn_infer.py` 的 `dim_check`**：优先用真值表（严格），回退 pint（仅取首单位，粗）。

**效果**：源头上 dc 边 **1130 → 10**；主图 dc 边 **1200 → 56**，其中**违规 0**。
保留下来的全是**物理正确的同量纲对**（energy↔torque、action↔ang_momentum↔planck、
impulse↔momentum、frequency↔omega、 stiffness↔surf_tension …）。

**顺带捕获的连带缺陷**（原报告未单列，修复轮一并处理）：
- `Phase13.Gate.B3` 的 33 条中有 **12 条量纲不成立**（把 `angular_momentum(ML²T⁻¹)` 与 `energy(ML²T⁻²)`、
  `voltage` 与 `efield` 判为"一致"—— pINT 只取首个单位所致）；
- `Phase13.GNN.typed` 的 25 条中有 **10 条**胡连（planck/grav_const 连到 concentration/amount…）；
- 人工策划 **1 条笔误**：`10_种子数据/build_classical_mechanics.py` 把 `("CM:pq:momentum","CM:pq:mass","p=mv")`
  误列入 `dimensionally_consistent`（动量 MLT⁻¹ ≠ 质量 M）→ **源头已删**（"p=mv" 语义本已由
  `CM:fo:momentum --derived_from--> PQ:mass/vel` 正确表达）。

## 3 · P0-2 · `norm_latex` 字符串清洗被当成数学等价证明

**根因**：`gnn_infer.py` 的 `norm_latex` 删掉全部 LaTeX 命令后小写，凡两式归一后相等即判
`same_as / R-MATH / VERIFIED`。**已独立复现**：`\sin(x)` 与 `\cos(x)` 都归一为 `(x)`。

**主图实证污染**：**1 条** —— `CM:fo:momentum --same_as[VERIFIED]--> RT:fo:rel_momentum`
（"动量公式"与"相对论动量公式"被判同一，来源 `Phase13.Gate.B6`）。

**修复**：边类型精确化为 **`same_latex_normalized`**，状态降为 **`NEEDS_REVIEW`**（不授 VERIFIED）；
主图该条已删除。前端新增配色。

## 4 · P0-3 · 校验器未声明"验证范围"

**根因**：门禁给出 `VERIFIED` 却从不说明**验证了什么、没验证什么**（铁律 #19：`verified` 不可作单一布尔）。

**修复（`04_验证闭环/verification_loop.py`）**
1. **新增 `SCOPE_BY_GATE`** 与 Verdict 字段 **`verification_scope`**：
   例如 `R-CHEM: explicit_atoms_plus_formal_charge; excludes:implicit_H/stereo/feasibility`。
2. **化学门禁实质增强**：
   - `count_atoms` **计入隐式氢**（`GetTotalNumHs` + `UpdatePropertyCache`）——`CO>>C=O`
     （CH₃OH → CH₂O）从"误判守恒"改为 **REJECTED**；
   - 新增**形式电荷守恒**（净电荷不等 → `R-CHEM-03`）——`[Na+]>>[Na]` 改为 **REJECTED**。
3. **数学门禁修正变量域**：`Symbol(s, real=True, positive=True)` → **`real=True`**（不假设正）——
   `sqrt(x²)=x` 从"恒成立"改为 **REJECTED**。
4. **物理门禁**声明"**仅**量纲齐次；未覆盖系数/物理意义/极限"。

> ⚠ **本轮同时发现一个报告未提的严重问题**：本机**未安装 RDKit**，化学门禁长期返回
> `NEEDS_REVIEW / R-CHEM-00` —— 即**化学验证在生产中形同虚设**。已安装 `rdkit 2026.09.1`
> 并纳入冻结反例集门禁（缺依赖 → 记 SKIP 而非 PASS，见 §6）。

## 6 · P0-5 · GNN 训练/测试泄漏

**根因**（`gnn_infer.py`）：`train_pairs` 用**全部边**（仅 `has_symbol` 下采样）；评估时又取**同一批**
`edge_by_type[rel]` 的前 10% 作测试 → **测试正样本已在训练集中**；节点结构特征亦取自全图边。
故 `avg_MRR 0.7037` 不可信。

**修复**
1. **先划分 holdout，再构训练子图**：按「无向对」整组划分（防 `(a,b)` 训练 / `(b,a)` 测试的反向泄漏），
   每关系留出 10%（上限 200 组）。
2. **邻接矩阵 / 关系掩码 `REL_MASK` / 节点结构特征（`out_et`/`in_et`）一律只用训练边**。
3. **新增断言守卫**：`assert not (train_triples & test_triples)`。
4. `pos_by_ru/pos_by_rv` 保留全图（仅供负采样与 filtered-eval 过滤，**不参与训练**）。

## 9 · 路线调整：A 研究原型（收敛版）

老板裁定**定位 A**。据此调整北极星与研发编排：

### 9.1 北极星重定义
- **旧**：跨域边计数 / 学科占比（易被"加同域质量"稀释——铁律 #18）
- **新**：**「固定任务集上，跨域结论正确且证据可追溯的比例」**
  —— 从"数边"转向"数**可被验证的结论**"，与本轮的可信性修复同向。

### 9.2 三层可信对象（第 18 轮落地，轻量版）
复用现有 `props.confidence / verification_gate / verification_scope` 范式，不引入微服务：
- **Claim**（结论，如"X 与 Y 同量纲"）
- **Evidence**（证据，指向门禁 + 反例集 + 数据源）
- **Verification**（分层记录：语法 / 量纲 / 守恒 / 电荷 / 变量域 / 来源 / 人工）

### 9.3 第 17~20 轮编排
| 轮次 | 主题 | 关键交付 |
|---|---|---|
| **17**（本轮 ✅） | **可信性修复轮** | 5 条 P0 源头修复 + 冻结反例集门禁 + 量纲真值表 |
| **18** | Claim/Evidence/Verification **轻量落地** | 结论—证据—验证三层对象；北极星改为"任务级可信完成率" |
| **19** | **跨域桥专题**：热力学—化学平衡—数学方法 | 真跨域桥（数学↔物理↔化学），替代"补学科"式扩容 |
| **20** | **复现工程**（无条件做） | 依赖锁 + 统一 CLI + release manifest + 小 demo |

**明确不做**：删物理节点 / 强行抬跨域占比（违铁律 #18）；以商业章否定研究价值。
