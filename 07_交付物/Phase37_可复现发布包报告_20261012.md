## 四、离线样例怎么选（确定性，可复现）

**目标**：小到可入库、又完整保留「节点 / 边 / 证据 / 跨域桥」四要素的研究样例。

**算法**（`make_sample.py`，全程无随机数、无时间戳）：

1. **种子 = 跨学科边**（学科判定一律走 `graph_export.subject_of`，与北极星仪器**同源**，铁律 #40）；
2. 按 **学科对分层轮转** 取种子（保证 6 个学科对都有代表）→ 避免 BFS 被单一学科吃满；
3. **BFS 扩展**：邻接按「语义优先级」（跨学科边 > `has_quantity`/`has_unit`/`uses_operator`/`derived_from`/`defines` > 其他 > `composed_of`）+ (is_strict, id) 稳定排序；
4. 节点/边数封顶；**只保留两端都在样例内的边**（无悬空）。

**同一份切片导出两种投影**（规范图 + 前端投影），并断言 id 集合相等。

## 七、边界与不主张（写进发布包 README）

1. 样例是**跨域桥核心切片**，不是完整图 —— 它是「可独立运行的验收入口」，不是「全量复现」。
2. 北极星 **99.65% 是规则门槛达标率**（分母 T1–T8），**不是跨域任务正确率**；
   必须同时披露分母构造、分母外占比（16.7%）与反向对照（83.5%）—— 单独出现的数字是误导（铁律 #50）。
3. `graph_scan` 的 25 条断言是**全图不变量**，在样例上无意义 → 样例模式只跑自包含子集，并**明确打印**该边界。
4. 依赖漂移**不阻塞运行**，但可能影响化学/量纲类数值细节；锁定版本与本机/复评环境的差异已在
   `requirements.lock` 与 `manifest.json` 中**显式披露**（复评环境 `rdkit 2026.3.6 / pint 0.26.1 / networkx 3.7 / numpy 2.5.3`）。
5. 清单的权威锚点是 **`artifacts[*].sha256`**；`git_head_at_build` 仅作上下文（发布提交为其后继），
   避免「清单自指提交号」的循环。
