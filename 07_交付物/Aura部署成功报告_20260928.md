## 2. 三大关键踩坑

### 2.1 凭证不是问题
最初报错 `Unable to retrieve routing information`，所有路径都以为是凭证错：
- ❌ 试了 `neo4j://853a33bc...`、`neo4j+s://...`、各种用户名组合（`neo4j` vs `853a33bc`）
- ❌ 试了 `database=None` vs `database='neo4j'` vs `database='853a33bc'`
- ❌ 加 `verify_connectivity()` 长超时 / 强制 retries / 自定义 resolver
- ❌ 全部 `ServiceUnavailable: Unable to retrieve routing information`

**真相**：Aura Browser 能正常访问（Aura 控制台显示 RUNNING），说明**实例完全健康**，问题在 driver 这一侧。

### 2.2 数据库名与用户名的真相
从下载的 `Neo4j-853a33bc-Created-2026-09-29.txt` 找到：
```
NEO4J_URI=neo4j+s://853a33bc.databases.neo4j.io
NEO4J_USERNAME=853a33bc           # ← Aura 免费实例的 username == instance ID
NEO4J_PASSWORD=***REDACTED***
NEO4J_DATABASE=853a33bc           # ← Aura 免费实例的 database == instance ID
```

**重要发现**：Aura 免费实例的 username 和 database 都等于 instance ID（前缀），不是常见的 `neo4j`。如果不指定 `database='853a33bc'`，driver 会尝试连默认库 `neo4j`，该库不存在 → 报 routing 错误。

### 2.3 自签名证书是终极根因 ⭐
直接 socket 测 7687 → TCP 通 → Bolt 握手返回空。  
Python `ssl.create_default_context()` → `SSLCertVerificationError: self-signed certificate in certificate chain`。

**Aura 免费实例用的是自签名证书**，Python 的 certifi 信任库不认它。但 Aura Browser 走的是 Aura 自家 WebSocket gateway，不验证客户端证书，所以浏览器能直接用。

**解决方案**：
1. Neo4j Python driver 6.x 规则：`trusted_certificates` / `ssl_context` / `encrypted` 配置 **仅适用于 `bolt://` 或 `neo4j://`**（无 +s 后缀）
2. 但 Aura 免费实例本身就需要 `+s`（加密）才能连
3. **正解：URI 用 `neo4j+ssc://`**（self-signed certificate，跳过证书验证）

```python
# 之前（错的）
uri = 'neo4j+s://853a33bc.databases.neo4j.io'   # ❌ 会因 cert verify failed 返回 routing 失败

# 现在（对的）
uri = 'neo4j+ssc://853a33bc.databases.neo4j.io'  # ✅ 跳过证书验证，连接成功
```

驱动一连上，SHOW DATABASES 立即返回实例详情（primary/writer/online），所有问题消失。

### 3.3 Cypher 25 兼容性修复
- ❌ 旧语法：`MATCH p = (a)-[*1..6]->(b) RETURN [n IN nodes(p)|n.id] AS path`  
  - Aura Cypher 25 不支持变长路径 `[*1..6]` 不带类型，也不支持列表推导
- ❌ 旧语法：`RETURN a.id + '->' + m1.id + ... AS path`  
  - `+` 在 Cypher 25 中被解读为 list concat
- ✅ 新语法：定长 3 跳 + 指定关系类型 + 返回 list
  ```cypher
  MATCH (a:Entity {id:'MX:thm:gauss_bonnet'})
  MATCH (a)-[:derived_from|proves]->(m1:Entity)
  MATCH (m1)-[:derived_from|proves]->(m2:Entity)
  MATCH (m2)-[:derived_from|proves]->(b:Entity {id:'MX:def:manifold'})
  RETURN [a.id, m1.id, m2.id, b.id] AS path
  LIMIT 5
  ```
- 关系类型在 Aura 中是**小写**（CSV 导入保留原大小写），不是 Cypher 常见的大写
