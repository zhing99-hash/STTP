# STTP v0.46 RC1 研发任务清单

**目标：** 把当前可运行工作目录收敛为可提交、可安装、可复现、可公开评审的候选版本。  
**规则：** RC1 完成前不新增图谱领域、不扩大节点规模、不新增 GNN/LLM 产品功能。

## P0：必须完成

| ID | 任务 | 验收标准 | 建议工期 |
|---|---|---|---:|
| RC1-01 | 建立真实发布分支与提交序列 | `git status --porcelain` 为空；Phase 49—55 报告所引 SHA 均可解析 | 1 天 |
| RC1-02 | 清点 422 项变化 | 源码/契约/必要数据入库；临时探针、缓存、生成物有明确去向 | 0.5 天 |
| RC1-03 | 重建证据基线 | `evidence_deps --check` 7 段全过；A04 不再因旧 HEAD 大面积 stale | 1 天 |
| RC1-04 | 修复谱系自检崩溃 | 未入库依赖返回结构化失败；frozen gate 108/108 | 0.5 天 |
| RC1-05 | 两趟完成发布链 | 先提交样例，再生成/提交 manifest；dirty/regenerated 两门均通过 | 0.5 天 |
| RC1-06 | 修复底部路径可信档 | 切换 verified/all 后 HTTP 请求含对应 `trust`，结果可发生预期变化 | 0.5 天 |
| RC1-07 | Python 3.11 干净安装 | wheel、editable install、6 个 CLI 入口、样例验证全部通过 | 0.5 天 |

## 发布产物

- `v0.46.0-rc1` tag 与可解析 commit SHA。
- 离线样例、manifest、sha256、LICENSE、NOTICE、DATA_LICENSES。
- Python 3.11 安装记录与浏览器 E2E 记录。
- 更新后的标准用户流程与五分钟演示脚本。
- 本次已知边界：未入库上游数据、元数据覆盖率、科学任务集性质、未支持的部署路径。

## 完成定义

RC1 完成不是“某个测试脚本显示通过”，而是：第三方从 tag 获取项目后，可以在 Python 3.11 环境安装、验证样例、启动页面、完成任务卡和路径查询，并得到与发布报告一致的快照 ID、查询结果和证据状态。
