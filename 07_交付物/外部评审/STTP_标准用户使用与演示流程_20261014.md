# STTP 标准用户使用与演示流程

**版本：** 2026-10-14  
**适用对象：** 研究人员、教师、学生、合作评审方和项目演示人员  
**推荐入口：** 离线公开样例。样例规模小、版本固定，适合首次体验和对外演示。

> 当前工作目录的搜索、路径和首次冷启动仍有待修复。本流程同时给出“当前内部试用方式”和“RC1 正式推广流程”。公开推广应在 RC1 门禁通过后进行。

## 1. 用户能够完成什么

STTP 用局部查询呈现跨学科知识，不要求用户一次浏览整张大图。标准体验包括：

1. 从概览了解图谱覆盖的学科和实体类型。
2. 输入关键词或从示例中选择公式、概念、物理量、分子或反应。
3. 生成有限规模的局部关系图。
4. 查看节点、关系、证据来源、新鲜度和验证状态。
5. 查询两个知识点之间的有限条关系路径。
6. 导出当前局部结果，用于复核、教学或后续分析。

STTP 是研究原型。结果用于知识导航和证据检查，不替代教材、标准、实验或专家判断。

## 2. 环境要求

- Windows 10/11、macOS 或 Linux。
- Python 3.11.x。当前项目声明范围为 `>=3.11,<3.12`。
- 推荐浏览器：Chrome 或 Edge 当前稳定版。
- 离线样例不需要 Neo4j、云数据库、API 密钥或互联网连接。
- 若使用 `bash sttp.sh sample`，Windows 需要 Git Bash；PowerShell 用户可使用下述纯 Python 启动方式。

## 5. 标准用户流程

### 步骤 1：确认运行状态

页面应显示后端在线、样例快照 ID 和图谱规模。若 15 秒后仍显示离线，停止服务并重新启动；正式推广版不应要求刷新页面。

### 步骤 2：先看概览

点击“概览”。向用户说明：概览中的节点是学科/类型聚合块，不是把全部节点同时画出来。这样可以在大规模图库中先确定方向，再进入局部图。

### 步骤 3：从问题或示例开始

RC1 推荐首页提供以下示例卡：

- “吉布斯自由能与熵之间有什么关系？”
- “这个公式的量纲是否一致？”
- “某个物理量有哪些单位与相关公式？”
- “某个分子由哪些元素或官能团组成？”

用户也可以输入关键词。系统先返回少量候选，用户确认实体后再查询，避免自然语言歧义直接污染结果。

### 步骤 4：设置局部图范围

首次查询使用以下默认值：

| 参数 | 推荐值 | 目的 |
|---|---:|---|
| 节点上限 | 40 | 保持首屏可读 |
| 边上限 | 70 | 避免高密度“毛线团” |
| 最大跳数 | 2 | 先看直接和近邻关系 |
| 超时 | 10,000 ms | 兼容首次冷查询 |
| 路径数 | 3—5 | 便于逐条解释 |

点击“生成子图”。如果结果被截断，先增加过滤条件；只有确有需要时才提高预算。

### 步骤 5：阅读结果

按照下面的固定顺序讲解：

1. **结论或摘要**：系统找到什么，或者为什么拒绝回答。
2. **关键节点**：公式、概念、物理量、单位、分子、反应或论文。
3. **关系边**：关系类型、方向和置信/验证状态。
4. **证据**：来源标识、定位信息、字节忠实度和验证依赖。
5. **边界**：`stale`、`needs_review`、`no_record`、`truncated`、`timeout` 的含义。

不要把 `stale` 解释为知识一定错误。它表示当前候选版本无法根据登记的权威字节确认其仍然新鲜。`no_record` 表示没有验证记录，也不能解释为已经验证。

### 步骤 6：逐步展开

选中一个节点后只展开一跳邻居。页面达到会话预算时，返回上一层或重置，不连续无边界扩张。一次演示只围绕一个问题展开，通常保持在 30—60 个节点即可。

### 步骤 7：查询关系路径

分别设置起点和终点，最大跳数 5，路径上限 3—5。系统应返回 `ok`、`truncated`、`no_result`、`timeout` 或 `error` 中的一种明确状态。`no_result` 只表示在当前快照和预算内没有路径。

当前版本前端路径协议尚未修复。内部开发人员可临时访问：

```text
http://127.0.0.1:8765/api/path?src=<节点ID>&dst=<节点ID>&max_paths=3&max_hops=5&deadline_ms=10000
```

正式推广时不得要求普通用户使用此临时接口。

### 步骤 8：导出与引用

导出当前局部结果时，一并保存：

- 快照 ID 和查询哈希；
- 查询参数和预算；
- 节点、边、证据与状态；
- 软件版本和导出日期。

截图适合展示，JSON 适合复核。论文或报告引用应同时引用原始来源，不只引用 STTP 页面。

## 6. 五分钟标准演示脚本

**0:00—0:40 定位。** “STTP 是可审计的跨学科公式知识图谱研究原型，重点是局部查询、来源追踪和明确拒答。”

**0:40—1:20 概览。** 展示学科/类型聚合图，说明全量图有 9,657 个节点、48,712 条边，前端不会一次渲染全部内容。

**1:20—2:40 局部任务。** 选择一个预置问题，以 40 节点、70 边、2 跳生成局部图，指出公式、物理量和关系边。

**2:40—3:40 证据。** 打开一条边的证据卡，解释来源、验证状态、`stale` 与 `no_record` 的差别。

**3:40—4:30 路径。** 查询两个节点的有限关系路径，展示截断或无结果也是受控状态。

**4:30—5:00 边界。** 说明这是研究原型，展示快照 ID 和导出功能，邀请用户复核数据或提供领域反馈。

## 7. 常见问题

### 页面显示离线

确认终端服务没有退出，并访问 `http://127.0.0.1:8765/api/stats`。当前开发版全图冷启动可能超过前端 2 秒探活预算；等待后刷新只能作为内部临时办法，RC1 必须修复。

### 搜索总是没有结果

当前开发版存在搜索参数未传入的问题。可用 `/api/search?q=manifold&limit=5` 判断后端是否正常；正式版修复后，界面必须区分空结果和接口错误。

### 查询超时或图太密

将节点/边预算降到 40/70，跳数降到 1—2；增加实体类型、关系类型或学科过滤。不要先提高到 500/2,000。

### 显示大量 stale

首先检查是否在干净的已提交版本运行。当前验证以 Git HEAD 中的字节为权威，未提交的新文件会使验证依赖失配。

### 安装提示 Python 版本不支持

使用 Python 3.11.x。项目当前不承诺支持 3.12。
