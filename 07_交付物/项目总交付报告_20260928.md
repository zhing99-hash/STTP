## 四、关键设计决策

1. **分而治之**：数学靠引用/推断依赖、物理靠量纲齐次、化学靠反应超图，Wikidata 做对齐层。
2. **置信度字段**：所有 `llm_inferred` 边必须带 `confidence` 与 `explicit_or_inferred`，可视化分色/降权。
3. **超大源零 OOM**：math-graph / ReactionAtlas / Wikidata 流式/惰性 + 先 1% 采样跑通。
4. **全局 id 约定**：`<source>:<local_id>`，仅 Align 后按 `wikidata_qid` 合并去重。
5. **Load 策略**：首建 `neo4j-admin import`（性能），增量 APOC MERGE。
