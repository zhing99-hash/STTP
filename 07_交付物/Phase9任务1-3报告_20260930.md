## 关键踩坑（本批次）

1. **Aura 远程逐条调用不可行**：125 次单条 Cypher 在免费实例超时 SIGKILL → 改批量 UNWIND。
2. **apoc.merge.node 唯一性约束冲突**：delta 把已存在节点（PQ:force/PQ:c 等 7 个映射量）又当新节点推，触发 IndexEntryConflict → 修正为映射量不写入 delta 节点列表（边按 id MATCH 命中已有节点）。
3. **增量去重**：同一物理量对在多方程重复出现，apoc.merge.relationship 按 (起点,终点,类型,kind) 去重，净增边数 < 生成边数（符合预期）。
4. **本地全量图文件被误叠加 raw 两次导致翻倍** → 改以 Aura 为权威源反向导出，保证 viz 与云端一致。
5. **rdkit 在 numpy 2.x 不可用** → 化学验证改用已存在 ground-truth（composed_of / real_reaction / equation 解析），不依赖 RDKit。
