### 2.2 ★ 本轮第一个教训：**HTTP 200 ≠ 数据可用**

三个「200」经**看响应体**当场证伪（铁律 #4：外部字段/接口语义先验证再用）：

- **A6 SABIO-RK**：返回 `<!DOCTYPE html>`（SPA 外壳）→ **老 REST API 已下线**，无 JSON。
- **B5 zbMATH**：返回合法 JSON，但作者名被替换为
  `"zbMATH Open Web Interface contents unavailable due to conflicting licenses."`
  → **接口在、内容被许可证屏蔽** ⇒ 不可用。
- **A10 BioCyc/MetaCyc**：返回营销首页 → 无批量端点（须授权/机器人访问）。

> **纪律**：可达性侦察**必须看响应体**，「HTTP 200」只证明 TCP+TLS+路由通。
> 这与既有铁律「TLS OK ≠ HTTP OK」同源，再进一层：**HTTP OK ≠ 数据 OK**。
