## 1. 目标与背景

Phase 8 的目标是把「合成适配器」替换为**真实数据源拉取**。路线图原定数学侧走
「MathXiv / ArxiTeX 增量拉取」。本轮先做**数据源可行性验证**，结果推翻了原计划的技术假设，
改用了另一条可达通道 —— 这是本轮最重要的判断。

---

## 2. 数据源勘查（关键发现）

### 2.1 沙箱出口白名单是「按域 **且按路径**」放行的

对 arXiv 的分层探测（TLS 握手 → 原始 HTTP）显示：**域名可达 ≠ 端点可达**。

| 端点 | 结果 |
|---|---|
| `export.arxiv.org/`（根） | ✅ HTTP 200 |
| **`export.arxiv.org/api/query`（官方 API）** | ❌ **TLS 可握手，但响应 0 字节超时** |
| `arxiv.org/abs/<id>` | ✅ HTTP 200 |
| `arxiv.org/list/math.NT/recent` | ✅ HTTP 200 |
| `arxiv.org/e-print/<id>` | ✅ 301（→ `/src`） |

**结论**：arXiv 官方 API 被**按路径**拦截；网页端点可达但需 HTML 抓取，元数据质量与稳定性都不如 API。

### 2.2 可达的开放学术 API（本轮新发现）

| 端点 | 结果 | 价值 |
|---|---|---|
| **`api.openalex.org`** | ✅ 200 | 开放学术图谱（works / 引用 / 主题），**CC0 授权** |
| `api.crossref.org` | ✅ 200 | DOI 元数据 / 引用 |
| `api.datacite.org` | ✅ 200 | 数据集 DOI |
| `api.semanticscholar.org` | ✅ 429（可达，需限速） | 引用图 |
| `export.arxiv.org/api/query` | ❌ 拦截 | — |

**决策**：改用 **OpenAlex**。它覆盖 arXiv 预印本与正式出版物，字段完整（标题/作者/年份/
引用次数/主主题/引用列表/DOI），可批量游标分页拉取，是比 arXiv API 更合适的真实源。

## 3. 设计与实现

### 3.1 拉取范围

- **子领域**：`Algebra and Number Theory`（`subfields/2602`）—— 承接 Phase 7 新建的数论切片（NT）。
- **筛选**：`type:article`，按 `cited_by_count` 降序。
- **规模**：初次 150 篇 + 高频被引补入 40 篇 → 去重后 **188 篇**；保留 `field=Mathematics` 的 **181 篇**。
- 年份跨度 1881–2020，共 **2304 条引用记录**。

### 3.2 Schema 演进 v0.1 → v0.2（新增文献层）

**新增节点 `Paper`**：`id = PA:oa:<OpenAlex-W-id>`，字段含 title / doi / year / pub_type /
cited_by / authors / venue / primary_topic / subfield / field / oa_status。

**新增边**：

| 边 | 语义 | `explicit_or_inferred` | 来源 |
|---|---|---|---|
| `cites` | Paper → Paper 真实引用 | `explicit` | OpenAlex `referenced_works` |
| `discusses` | Paper → MathConcept 主题对齐 | `inferred` | 主题映射 |
| `part_of` | MathConcept → MathConcept 概念包含 | `inferred` | 领域公理 |

**新增概念节点**：`NT:mc:number_theory`（数论）、`MA:mc:abstract_algebra`（抽象代数），
并把既有 5 个数论概念（素数/同余/模算术/欧拉函数/最大公约数）以 `part_of` 挂到「数论」下。

### 3.3 一个必须避开的陷阱（外部字段语义）

**不使用 OpenAlex 的 `concepts` 字段做概念匹配**。该字段存在明显消歧错误，实测高频项含：

```
21  Prime (order theory)     ← 序理论的"素元"，不是数论素数
15  Ring (chemistry)         ← 化学的"环"，不是代数环
14  Calculus (dental)        ← 牙结石，不是微积分
12  Dentistry                ← 牙科
```

若用 `prime` 匹配图中的 `NT:mc:prime`，会把 21 篇序理论论文**错误挂到数论素数**上。
本层改用质量更高的 **`primary_topic`**（OpenAlex 新主题体系）做**粗粒度、语义正确**的
领域对齐 —— 宁可桥接稀疏，也不臆造。这与 ElementKG `HASATOMIC`、PhysicsBabel `score`
是同一类教训：**外部数据源字段语义必须先验证再使用**。

### 3.4 主题 → 概念映射（人工、透明、可审计）

```
Analytic Number Theory Research          -> NT:mc:number_theory
Algebraic Geometry and Number Theory     -> NT:mc:number_theory
Advanced Mathematical Identities         -> NT:mc:number_theory
Rings, Modules, and Algebras             -> MA:mc:abstract_algebra
Advanced Topics in Algebra               -> MA:mc:abstract_algebra
Commutative Algebra and Its Applications -> MA:mc:abstract_algebra
```
