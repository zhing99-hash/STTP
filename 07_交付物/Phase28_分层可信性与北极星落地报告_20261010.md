## 2 · 为什么必须分层（铁律 #19）

`verified` 作为单一布尔把**四类语义完全不同**的东西压成一个 `True`：

| 类别 | 例子 | 能否叫「验证」 |
|---|---|---|
| 构造性事实 | 元素符号、分子式解析计数 | 结论真，但**无判断空间** |
| 确定性规则校验 | 量纲齐次、原子/电荷守恒、周期表位置 | 是，可复算 |
| 多源一致 | PubChem inchikey 三方交叉 | 是，但须**第二源真独立** |
| **模型预测** | GNN / LLM 链接预测 | **不是**（最严重：把预测冒充验证） |

Phase 27 后实测：27545 条 `verified=True` 中，`kind ∈ {gnn_typed_verified, llm_inferred*}` 的达 **850 条**，
`has_symbol|real|PhysicsBabel` 达 **24104 条**（塔自动义，与物理门禁无关）。→ 单一布尔必然通胀。

## 3 · 分层受控词表与口径

新建 **`11_真实数据/verification_model.py`**：边级分类器 + 独立复算 + 审计器。

**受控词表（由弱到强）**

| # | level | 含义 |
|---|---|---|
| 0 | `unverified` | 无验证依据（未分类 / 来源不明） |
| 1 | `model_inferred` | **模型（GNN/LLM）推断，不构成验证** |
| 2 | `source_asserted` | 单一来源 / 仓库内策划**直接断言**，未独立复核 |
| 3 | `by_construction` | 权威表 / 概念定义**构造性产生**（无判断空间） |
| 4 | `rule_checked` | **确定性规则 / 算法校验**通过（独立实现、可复算） |
| 5 | `cross_source` | **≥2 独立来源一致** |
| 6 | `human_reviewed` | 人工复核确认 |

**口径**
```
verified         = level ≥ by_construction   → 33644
verified_strict  = level ≥ rule_checked      → 33607   ← 北极星口径
```

**分级原则 ——「证据优先于提出者」**（`classify()` 的 A/B 两段结构）

- **A 段（与提出者无关的确定性复算）**：只要复算可判且**通过** → `rule_checked`；
  复算**判否** → `unverified` + note（真实缺陷，进审计清单）；
  复算**不可判定** → 落到 B 段，**不猜、不放水**。
- **B 段（无独立复算可用）**：按来源定级 —— 模型产物 → `model_inferred`；外部源 / 策划 → `source_asserted`。

**独立性守卫（铁律 #14）**：`cross_source` 要求**第二源真的独立** ——
`composed_of` 仅当节点权威式为 `pubchem_formula`（PubChem）**且边自身不是** `source=="PubChem"` 的
`from_formula` 时才给 `cross_source`。仅凭「模型自述的分子式」内部一致**不得**升级。
→ 该守卫把虚高的 `cross_source` 从 **3400 压到 2608**。

## 6 · 本轮新坐实的 P0-7 · 库内虚假门禁归因未撤回

**如何发现**：把 Phase 28 新写的两条**落库不变量**冻结进反例集后，**首次运行即 FAIL**：

```
❌ P0-5-main-has-symbol-no-phy-gate [graph_scan] 命中 24104
```

**根因（铁律 #15：下游打补丁 = 源头有错的信号）**
Phase 27 的「归因纠正」**只改了派生字段 `verification_scope`**，
却把**已存**的 `verification_gate` 原样留在权威图里 —— 于是库里仍留着一句
「某个**从未跑过**的门禁验过它」的假话。审计打印的"②（已改正）"与实际落库状态**不一致**。

**全量范围（24975 条）**

| 边类型 | 存量归因 gate | 派生 scope | 条数 |
|---|---|---|---:|
| `has_symbol` | R-PHY | formula_participation_membership | **24104** |
| `has_quantity` | R-PHY | model_link_prediction | 725 |
| `has_quantity` | R-CHEM | model_link_prediction | 59 |
| `related_to` | R-CHEM | model_link_prediction | 49 |
| `reactant_of` | R-CHEM | model_link_prediction | 20 |
| `dimensionally_consistent` | R-PHY | model_link_prediction | 8 |
| `product_of` | R-CHEM | model_link_prediction | 8 |
| `chemical_reaction` | R-CHEM | model_link_prediction | 2 |
| | | **合计** | **24975** |

**修复**：delta 加 (2c) 步 —— 凡 `not _gate_matches_scope(gate, scope)` 的边，
`verification_gate := "NONE"`，旧值留痕在 `verification_gate_withdrawn`（可追溯、不销毁证据）。
**修复后**：`已归因 2620 条，归因-范围不符 0 条`。

## 10 · 遗留与下一轮建议

**本轮遗留**
1. **面向任务的 `evidence[]` 对象化未做** —— 本轮只落到 `verification_scope` + `verifier` + `note` 层面，
   尚未引入独立的 `Claim / Evidence[]` 结构（`{claim, evidence[], verification_scope, verifier}`）。
2. **陈旧 repr 串的生成链根治未做** —— `06_PoC/build_phase11/11b/12.py` 的「viz 投影 → 回写 raw」往返
   仍可能再次把投影层字符串化形态冻进权威图（本轮只做了**恢复 + 读取侧容错**）。
3. **Aura 侧属性形态不对称** —— 本地 `dim_exponents` 为 dict，DB 边界 JSON 化为**字符串**
   （Neo4j 属性不支持嵌套 map）。旧库存的是非法 JSON 的 repr 串，现在改为合法 JSON 串（改进但仍是"字符串"）。
4. T3 量纲达标率 56.4%：`dim_ok` 仍有 24 条不可判定（3 个光学量缺 J 基未解）。
5. T7 跨域桥 0/53 —— 北极星最短板，需**跨域桥专项**。

**下一轮（第 19 轮）建议：跨域桥专项（Toward Cross-Domain Bridges）**
- 首选 **DLMF**（可达）：数学↔物理，现仅 29 条数学↔物理跨域边；
- 或 **NIST Chemistry WebBook** 热化学量（化学↔物理）；
- 验收口径用 **T7 达标率**（`human_reviewed` 门槛）与**宽口径跨域边 ≥rule_checked 条数**成对读。
