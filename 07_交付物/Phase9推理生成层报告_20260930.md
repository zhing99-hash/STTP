# Phase 9 · 推理生成层规模化报告（2026-09-30）

## 一、背景与缺口
原四层架构：**数据层 → 知识层(Neo4j/Aura) → 推理生成层(GNN+LLM+符号校验) → 交互层**。
前三层已在 Aura 2077 节点 / 7597 边图上实打实搭好，唯独**推理生成层此前只在 36 节点小图演示过（Phase 3/5）**，从未在真实大图规模化运行 —— 这是核心架构缺口。本阶段在真实 2077 节点图上重跑 GNN 推断 + LLM 假设 + 符号校验闭环，补全第四层。

## 二、方法与管线
脚本：`09_科研扩展/9_inference/gnn_infer.py`，产出 `phase9_raw.json`(Aura 增量, nodes=[]) / `phase9_candidates.json`(人工复核明细)。

1. **GNN 链接预测（桥接导向）**
   - 图：2077 节点 / 7597 边；节点特征 = 类型 one-hot(16) + 学科 one-hot(5) + log(度) + 是否有公式(共 23 维) + 对称归一化邻接。
   - 模型：2 层 GraphSAGE（邻居均值聚合），隐 64，输出 64，cosine 打分。
   - **训练策略关键修正**：正样本 = 132 条已有跨域边，负样本 = 3000 条跨域非边（而非全部 7597 边）。原"全边训练"被 98% 同域内边淹没，跨域信号归零、top 候选全是孤立节点退化向量（cosine=1.0 伪影）。桥接导向训练后 pos/sigmoid=0.99、neg=0.50。
   - 共枚举 **555,899 对跨域候选**，已有跨域边仅 132 —— GNN 补桥空间巨大。

2. **符号校验门控（三类）**
   - **R-PHY（pint 量纲）**：两端均经 `has_unit` 拿到 Unit.symbol，比对 pint 量纲是否一致。
   - **R-CHEM（数据组成 / 反应方程）**：`composed_of` 真实组成比对；解析 Reaction.equation 左右式（去系数），命中则判反应物/产物。**不依赖 RDKit**（本解释器 numpy 2.x 冲突不可用），改用既有真实数据校验。
   - **R-MATH（sympy）**：公式 latex 轻量校验。

3. **产出策略**
   - 显式挖掘可校验跨域桥：跨域物理量量纲一致 + 分子(化学)↔质量类物理量(跨域) 摩尔质量桥（组成校验可证）。
   - GNN top 候选经门控后，VERIFIED 升权、REJECTED 丢弃、NEEDS_REVIEW 降权沉淀。

## 四、关键发现
**真实数据已把绝大多数可符号证实的跨域关系（composed_of / real_reaction / has_unit / same_as）填进图**，因此纯符号可证的新跨域边有限（仅 60 条），其余以 `NEEDS_REVIEW` 假设形式沉淀待人工/LLM 复核。这恰是 Phase 3「推断边须置信度标注降权」原则的规模化落地 —— 推理层不是"无中生有造边"，而是"在可验证处确认、在不可验证处诚实标注"。
