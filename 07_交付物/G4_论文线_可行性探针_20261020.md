## 〇、一句话结论

> **「5,090 个公式都有论文讨论」不是一个数据缺口，是一个范畴错误。**
> 其中 **5,002 条从来没有被任何人写出过** —— 它们的 `name` 就是 LaTeX 式子本身
> （`m = k₀ · F·S·i⁻²·ρ_e⁻¹`），文献里不存在讨论它的论文，再多抓一万篇也是 0。
> 真正可建立文献关联的，是 **80 条 `curated_seed` 具名公式**（物理 38 条）。

这是继 G2（「一个公式属一个学科」前提错）、G3（「每个公式都有适用条件」前提错）
之后**第三次同类前提错误**。前两次都靠探针在动手前拦住，这次也一样。

## 一、R1　现有的 178 条 `discusses` 与公式**毫无关系**

| 项 | 实测 |
|---|---|
| `discusses` 边总数 | 178 |
| 端点类型 | **Paper → MathConcept：178（100%）** |
| 其中有一端是 Formula 的 | **0** |
| Paper 节点 | 181 |

公式作为端点的边只有这些：`has_symbol` 24,330 / `defines` 115 / `derived_from` 43+29 /
`same_as` 16+3 / `uses_operator` 11+8 / `related_to` 3+2。

**含义**：规划里「P 级从『数学 178 条』扩到物理侧」这句话，
如果照字面理解成「再加一些 Paper→物理主题的边」，**得到的仍然是主题级边，不是公式级**。
`discusses` 这个边名具有误导性 —— 它说的是「这篇论文讨论这个**概念**」，
从来没有「讨论这个**公式**」这一层。

## 二、R2　公式有没有可被文献指称的名字（本线真正的 Go/No-Go）

| 项 | 实测 |
|---|---|
| 公式总数 | 5,090 |
| `name` 含 ≥4 字母英文词 | **88（1.73%）** |
| PhysicsBabel 公式 | 5,000，**有人类名 0 条** |
| **PB 的 `name` == `latex`** | **5,000 / 5,000（100.0%）** |

PB 名字样例：

```
A = k₀ · m²·Lₐ⁻²·Q²
A = k₀ · m²·S⁻²·Q²
A = k₀ · m²·a²·k⁻²
```

这 5,000 条是**量纲合成式**：由 `m, ℓ, t, F, S, i, ρ_e …` 按量纲齐次性枚举出来的
单项式。它们不是任何一条被写下来的物理定律 —— 是「所有量纲合法的组合」。
**没有指称对象，就不存在「被论文讨论」这件事。**

> 这与 G3 的 `no_referent` 是**同一个东西的两面**：G3 发现它们没有适用条件，
> 因为「谁也不是」，所以「在什么条件下成立」无从谈起；现在发现它们也没有文献，
> 因为「谁也不是」，所以「谁讨论过它」也无从谈起。

## 四、R4　PhysicsBabel 原文里没有任何文献锚点

- `physicsbabel_raw.json` 结构：`{nodes: 5,050, edges: [...]}`，props 字段为
  `name, domain, source, latex, equation, dim_exponents, pb_domains, dim_homogeneous, dim_scope, dim_verified_by, …`
- 文献类字段：按**字段名**查 0 个；按**取值**（有没有 DOI / arXiv / URL / 作者列表）查 0 个。
- 唯一的 `source` 取值 100% 是 `'PhysicsBabel'` —— 那是**生成器名**，是 provenance 不是 citation。

> 这一条是探针自己抓出来的错：第一版正则把 `source` 算作文献字段，报「有 1 个」。
> 判据必须按**取值**判，不能按字段名判。

## 五、R5　摘要拿得到，但本仓库没存

| 项 | 实测 |
|---|---|
| `openalex_math_raw.json` 里 works | 188 |
| 其中带摘要 | **0** |

## 六、R6　命中数不能当「被讨论数」—— 这是本报告最要紧的一张表

同一批合成式，只改写法，命中量相差 **4 个数量级**：

| 档 | 查询 | 命中 |
|---|---|---:|
| 精确串（含 Unicode 数学符号） | `m = k₀ · F·S·i⁻²·ρ_e⁻¹` | **0** |
| 宽松分词（去掉符号） | `k0 F S i^-2 rho_e^-1` | 3（相机设计 / 激光烧蚀 —— **假阳性**） |
| 同类合成式换一种写法 | `F = k0 m^2 v^3 S^-1` | **92,302** |
| 人类具名 · 物理 | `Coulomb's law` | 15,595 |
| 人类具名 · 化学 | `Nernst equation` | 49,050 |
| 人类具名 · 相对论 | `Mass-energy equivalence` | 165,584 |

两条结论：

1. **合成式一侧没有判别带**：严格匹配给 0，宽松匹配给 9 万。中间不存在
   「既能召回又可信」的阈值 —— 因为**本来就没有正例**，能被召回的全是噪声。
2. **具名公式一侧有召回但没精度**：`Coulomb's law` 命中 15,595 篇，
   绝大多数只是**提了一次名字**。`提及（mention）≠ 讨论（discuss）`。
   若把 15,595 写成「Coulomb 定律被 15,595 篇论文讨论」，这是**可被一眼击穿的过度宣称**。

## 七、R7　裁决

| # | 裁决 | 依据 |
|---|---|---|
| V1 | 现有 178 条 `discusses` 与公式无关 | R1：Formula 端点为 0 |
| V2 | 「5,090 个公式都有论文讨论」**不可达** | R2：有人类名 88 条，其余 5,002 条 name 就是 LaTeX 式子 |
| V3 | 物理侧可达量级是**几十条**而非几千条 | R3：物理 curated 38 条（唯一名 37） |
| V4 | PB 原文没有文献锚点 | R4：按名/按值两路，文献字段均 0 |
| V5 | 摘要字段拿得到，本仓库没存 | R5：188 条 works 摘要 0 条；`fields/31` 86% 有 |
| V6 | 命中数不能当「被讨论数」 | R6：合成式 0 ↔ 符号汤 92,302 |

### 唯一诚实的做法：三态标注（与 G3 的 `applicability` 同构）

| 状态 | 含义 | 预估条数 |
|---|---|---:|
| `extracted` | curated 具名公式，检索到**带定位句**的文献 ⇒ 建 `mentioned_in` 边 | ≤ 38（物理） |
| `no_referent` | 无人类可读名的公式，从未被任何人写出 | 5,002 |
| `not_extracted` | curated 里检索不到（名字太泛/文献太旧/闭源） | ≥ 0 |

### ✗ 不许做的三件事

1. **拿 `concepts` / `topics` 回填成「公式被讨论」** —— 那是主题，不是公式。做了就等于
   把 R1 那个误导性边名再复制一遍。
2. **拿符号汤检索的命中数当证据** —— 92,302 篇是噪声，不是 9 万个讨论。
3. **把 `no_referent` 算成欠账写进覆盖率分母** —— 与 G3 同一条纪律：无指称不是欠账。

## 八、这对 RC1 报告意味着什么

`07_交付物/RC1_整体状态评估_20261020.md` 里那句「5,090 个公式中被论文讨论数 = 0」
**表述不够准确**，应按本报告改写为：

> 可建立文献关联的具名公式 80 条（物理 38 条），目前 **0 条**已建；
> 其余 5,002 条为量纲合成式，**无文献指称对象**（`no_referent`）。

差别在于：前一句读起来像「系统还没抓到论文」（努力问题），
后一句是「这些公式本来就不在文献里」（范畴问题）。对外必须说后一句。
