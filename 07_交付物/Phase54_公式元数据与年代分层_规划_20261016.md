## 2. 数据模型设计

### 2.1 四个新属性键（仅 `Formula` 节点）

| 键 | 含义 | 有值时 | 无值时 |
|---|---|---|---|
| `discovery_time` | 发现时间 | 年份文本，见 §2.1.1 的**合法形态** | **写 `"暂无"`**（决策 4） |
| `discoverer` | 发现人 | 人名，如 `"Isaac Newton"` | **写 `"暂无"`**（决策 4） |
| `description` | 公式介绍（这段式子在说什么） | 一句话中文 | **不写该键**（已确认） |
| `usage` | 使用描述（怎么用它） | 一句话中文 | **不写该键**（你已明确） |

**已确认（原待确认点 ① 的结论）**：`description` 与 `usage` **同规则** —— 无值 ⇒ 不写键、前端不渲染该行。
即「暂无」只用于 `discovery_time` / `discoverer` 两个字段。

#### 2.1.1 `discovery_time` 的合法形态（★ 起草时实测出的必要扩充）

起草 81 条时立刻撞到一个缺口：**公元 1000 年以前只有 1–3 位数字**（如花拉子米《代数学》约 820 年），
而「四位年份」形态表达不了它。故合法形态定为 **4 种**（比原规划多 1 种）：

| 形态 | 例 | 说明 |
|---|---|---|
| 四位数字年份 | `"1687"` / `"1909"` | 1000–9999 年 |
| `公元 N`（N 为 1–3 位数字） | `"公元 820"` | **本次新增** —— 公元 1–999 年 |
| `公元前 N`（N 为 1–4 位数字） | `"公元前 300"` | 公元前的年份 |
| `暂无` | `"暂无"` | 确不可考（哨兵值） |

★ **已确认（原待确认点 ②）**：`"暂无"` 是**哨兵值**（sentinel），不是普通文本。为免它被下游误解析
（例如当成年份 0、或当成可排序字符串）：
- 新脚本**断言**取值恰在上述 4 种形态内，**非法值一律拒绝落盘**（fail-closed，铁律 #62）；
- 分桶函数对 `"暂无"` 直接返回 `"暂无"`，**永不**落进任何真实年代桶（`M6` 断言）。

#### 2.1.2 只有「世纪」级精度的古代结果怎么记（起草纪律）

若某结果只能定到某个世纪（如《孙子算经》约公元 3–5 世纪），**取该世纪的代表年份**写入
`discovery_time`，并**必须**在 `meta_source` 里显式写「约」。例如
`"公元 400"` + `meta_source: "《孙子算经》约公元 3–5 世纪（取 4 世纪代表年）"`。
⇒ 既不丢信息，也不伪装成"确有其年"。

### 2.2 依据字段（可追溯性，项目纪律）

每条策展元数据**必须**带 `meta_source`（依据），例如
`"Newton, Philosophiæ Naturalis Principia Mathematica (1687)"`。
**断言**：`discovery_time` 或 `discoverer` 有值（≠「暂无」）时，`meta_source` **必须**存在。
⇒ 防止出现「凭空写了一个年份」。

### 2.3 派生字段 `era`（**不入库**，运行时算）

由 `discovery_time` 派生年代桶标签，规则（决策 2）：

| 输入 | `era` | 依据 |
|---|---|---|
| `"1687"` | `"17 世纪"` | ⌈1687/100⌉ = 17 |
| `"820"` → 写作 `"公元 820"` | `"公元 9 世纪"` | ⌈820/100⌉ = 9 |
| `"公元前 300"` | `"公元前 3 世纪"` | ⌈300/100⌉ = 3 |
| `"1909"` | `"1900–1909"` | 1900 起切十年桶 |
| `"1910"` | `"1910–1919"` | 同上 |
| `"暂无"` / 键缺席 / 非 Formula 节点 | `"暂无"` | 哨兵值直通 |

**边界**（必须逐值断言）：`1899` ⇒ `"19 世纪"`；`1900` ⇒ `"1900–1909"`（**跨过 1900 即切到十年桶**）；
`公元 900` ⇒ `"公元 9 世纪"`；`公元 901` ⇒ `"公元 10 世纪"`。

★ **唯一实现**（铁律 #88）：分桶函数**只写一份**，放前端 `core.js`，
并由前端自检的**边界表**逐值断言；后端不参与（因决策 3）。
★ 桶标签**必须可排序**：`公元前 *` < `公元 *` < `N 世纪` < `NNNN–NNNN`（图例按此序排列）。

## 3. 元数据内容：81 条的起草原则

81 条全是教科书级公式，答案**公开可核验**。逐条判断：

| 情形 | 处理 |
|---|---|
| 有明确的单一发现人 / 年份 | 写实（如 牛顿第二定律 1687、欧姆定律 1827、薛定谔方程 1926） |
| 多人渐进 / 归属有争议 | 写主要贡献者 + 最早年份，**依据里注明「渐进」**（如理想气体状态定律：玻意耳 1662 / 查理 1787 / 盖-吕萨克 1809） |
| 经验总结 / 定义性、确无可考 | **标「暂无」**（诚实——如部分化学经验式） |
| 古代结果（如勾股定理、欧几里得算法） | 写早期文献年代 + 依据（如《几何原本》约公元前 300） |
| **纯定义式 / 组合式**（如 `v=c/n`、`Q=[C][D]/[A][B]`） | 无单一"发现"事件 ⇒ **标「暂无」**；`description` 仍写清它在定义什么 |

**预期结果**：81 条中大部分能写实；少数标「暂无」。
**5000 条 PhysicsBabel 一律「暂无」**（上游无此信息，且不臆造）。
