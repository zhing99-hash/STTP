## 三、真实执行验证（实跑证据）
`python phase3_demo.py`：
- 载入图谱：22 节点 / 44 边
- LLM 生成候选：**16 条**（化学 4 / 物理 4 / 数学 8）
- 校验判决：**VERIFIED 8（50%）/ REJECTED 8（50%）/ NEEDS_REVIEW 0**
- 门禁分布：R-CHEM 4、R-PHY 4、R-MATH 8
- 校验后置信度：avg 0.4944 / min 0.06 / max 0.90
- 回写图谱：**8 条 VERIFIED 推断边**（R-CHEM 2 / R-PHY 2 / R-MATH 4）→ 总 **52 边**

**典型案例**
- ✅ R-CHEM `C+O2→CO2`：原子守恒 `{C:1,O:2}=={C:1,O:2}`，置信 0.7→0.9
- ❌ R-CHEM `C+O2→CO`：R-CHEM-01（O 原子差 1），置信 0.55→0.11
- ✅ R-PHY `F=ma`：量纲一致 MLT⁻²，置信 0.8→0.9
- ❌ R-PHY `F=mv`：R-PHY-01 量纲不一致 MLT⁻²≠MLT⁻¹，置信 0.4→0.08
- ✅ R-MATH `(a+b)²=a²+2ab+b²`：LHS−RHS=0，置信 0.75→0.9
- ❌ R-MATH `(a+b)²=a²+2ab+b²+1`：R-MATH-01（LHS−RHS=−1≠0），置信 0.5→0.10

**门禁路由**：化学类→RDKit 原子守恒；量纲类→pint 齐次性；数学类→SymPy 等式；其他→NEEDS_REVIEW。

## 四、关键设计
- **零 API Key 依赖**：heuristic 模式内置 14 条真假混合候选，覆盖三学科；`backend='api'` 在缺 `OPENAI_API_KEY` 时自动降级为 heuristic（友好提示、不崩）。
- **真实门禁**：验证必须真正调用 RDKit/pint/SymPy，不造假。
- **缺库不崩**：各 gate 自带 import 守卫，缺失库返回 NEEDS_REVIEW。
- **置信度策略**：VERIFIED→`max(初始,0.9)`；REJECTED→`初始×0.2`；NEEDS_REVIEW→`初始×0.5`（低置信待审）。
- **回写规范**：VERIFIED 推断边追加到 `with_inferred.json`，每条带 `verified` / `verification_gate` / `verification_evidence` / `explicit_or_inferred='inferred'`。

## 五、闭环价值
形成可迭代的「假设—验证」飞轮：LLM 扩展图谱覆盖率，符号引擎守住正确性底线，推断边带置信度且被降权/拒入，避免错误知识污染知识库。
