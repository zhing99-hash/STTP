## 二、B5 · 数据源可达性探测工具（新增基础设施）

### 2.1 为什么要固化成工具

本项目已在**多轮**重复做「某网站能不能访问」的探测，且每次都踩同一类坑，故把方法论固化为
`11_真实数据/probe_sources.py`：

```
python 11_真实数据/probe_sources.py [--only <key>…] [--rounds 3] [--json <path>]
```

它对每个目标做 **三层递进 × N 轮 × 双通道（直连 / 代理）**：
**L1 TCP 443 → L2 TLS 握手 → L3 真实 HTTP 请求并读到响应体**。

判定口径：`OK` / `FLAKY`（有成功有失败）/ `PATH_BLOCK`（TLS 通但响应体空/超时）
/ `TLS_BLOCK` / `TCP_BLOCK`。

## 三、B6 · 文献层多源交叉校验（Crossref + DataCite）

### 3.1 动机

Phase 8 首步的 181 篇数学文献来自 **OpenAlex 单一来源**。而本项目已多次踩到
「外部字段语义/取值不可想当然」（ElementKG `HASATOMIC` 把族号当原子序数、
PhysicsBabel `score` 实为复杂度取反、OpenAlex `concepts` 有消歧错误）——
文献层元数据同样需要**独立信源交叉校验**。

### 3.2 产出

`11_真实数据/literature_validate.py`（`--fetch` / `--check` / `--build`），
按 DOI 先查 Crossref、404 再兜底 DataCite（数据集/预印本/机构库）：

| 指标 | 值 |
|---|---|
| Paper 总数 | 181 |
| 有 DOI | 163 |
| **校验命中** | **163 / 163（100%）**（Crossref 161 · DataCite 2） |
| 无 DOI（不适用） | 18 |
| 带一致性 flag | 39 |

写入图谱（`phase21`，纯属性增强，**0 新增节点/边**）：
`doi_verified` / `doi_verified_via` / `crossref_cited_by` / `crossref_reference_count`
/ `crossref_type` / `crossref_container_title` / `crossref_author_count` /
`publisher` / `issn` / `license_url` / `crossref_year` / `doi_check_flags`。

### 3.3 发现（重要）

**① 一个解析缺陷（本是适配器 bug，非数据问题）**
Crossref 的标题/刊名含**双重转义的 HTML 实体**：

```
M&amp;#233;moires de la Soci&amp;#233;t&amp;#233; math&amp;#233;matique
   ↑ 需两次 html.unescape 才还原为 Mémoires de la Société mathématique
```

初版只 `unescape` 一次，导致**误报 3 条「刊名不一致」**。修掉后刊名不一致由 4 条降至 3 条，
且这 3 条经逐一核对**全是合理差异**（仓储记录 vs 正式刊名、刊名缩写 vs 全称），无一是错误。

**② 引用计数：Crossref 与 OpenAlex 口径不同，不可互相覆盖**

| 口径 | 说明 | 本轮数据 |
|---|---|---|
| OpenAlex `cited_by` | 索引范围广（含体系外文献） | 基准 |
| Crossref `is-referenced-by-count` | **只统计 Crossref 体系内的引用** | 中位比值 **0.62** |

32 篇出现「Crossref 显著低于 OpenAlex」（老数学专著尤甚：*Introduction to Analytic Number Theory* 2693 vs 69）——
**这是口径差异，属预期**，因此本模块**不做覆盖**，只作独立第二口径保留，并把此类情形标为
`citation_caliber_gap`（预期）而非错误。

由此还新增了一条**反向异常检测**（Crossref 本应是子集，若反超则可疑），精确揪出 **1 篇**：

```
⛔ W2322753244  Pseudo-Inverses in Associative Rings and Semigroups (1958)
   OpenAlex=711  vs  Crossref=1342   → 待复核
```

**③ 检出 1 处 OpenAlex 真实年份错误**（`year_mismatch` 共 2 条，另 1 条属口径差异）

```
PA:oa:W2005936791  Prime Numbers: A Computational Perspective
  DOI 10.1007/0-387-28979-8  → Crossref: 2005 年书（Springer-Verlag）
                             → 图谱(OpenAlex): 2012
```

DOI 是同一身份，而 Crossref 是 DOI 注册机构，故 **2005 为准**。
处理方式：**只记 flag、不改原值**（`doi_check_flags=["year_mismatch"]` + `crossref_year`），
保持可回溯；本条列为待人工裁定。
另一条 `Deformations of Lie algebras using σ-derivations`（图谱 2005 / Crossref 2006）
是典型的**在线优先 vs 正式印刷**年份差，非错误。

## 五、一个重要的「阴性结论」：分子多节点**不是缺陷**

### 5.1 起因

盘点分子层时发现：**754 个 `Molecule` 节点分布在 8 套命名空间**
（`EK2:mol:*` 713 个，其余 41 个散在 `MO` / `OM` / `IC` / `BC` / `PC` / `MX` / `CE`），
且存在明显撞名，例如「水」同时是 `MO:h2o`、`IC:mo:h2o`、`BC:mo:h2o`。
初判结论为：**这与元素层 A5 是同一类重复缺陷**，并已着手设计「分子命名空间归一」。

### 5.2 验证后推翻

在动手前按项目惯例先查「这些节点之间是否已有显式关联」，结果如下：

```
MO:h2o   ←seed_to_existing→   IC:mo:h2o, BC:mo:h2o
MO:h2o   ←pubchem_bridge→     PC:mol:962
PC:mol:962 ←skeleton_bridge / cross_source_alignment→ EK2:mol:molecule_962
MX:chem:co2 ←SAME_AS→ WD:Q1997 / ek:molecule:CO2 / wd:Q_carbon_dioxide
```

**这些"重复"节点已被 `same_as` 边显式关联，且每条边都带 provenance（`kind`）。**

→ 结论：这是**有意的跨源对齐设计** —— 保留各来源的原生节点（各自的策展边、
学科视角与来源标注），再用 `same_as` 声明它们指同一实体。
**若按原计划合并，会破坏 provenance 并丢失各学科视角的策展边**（例如
`IC:mo:h2o` 的「无机化学」视角、`BC:mo:h2o` 的「生化」视角）。

故**不做合并**。这也解释了为什么 `PC:mol:*` 这类"疑似冗余"节点上挂有 GNN 推断的
`has_quantity` 边 —— 它们是**对齐层的一部分，而非脏数据**。

> 备注：该设计确实带来已知副作用——同一实体多节点会稀释 GNN 嵌入
> （即记忆中「超级枢纽 / 嵌入趋同」的成因）。若后续要缓解，正确做法是
> **在 GNN 特征中显式注入 `same_as` 邻接**或做**连通分量级嵌入池化**，
> 而不是删除节点。本条留作候选议题。

## 七、源头与缺陷修复

按项目铁律「**改数据前先改源头**」，本轮修掉 2 处**自己引入/遗漏**的缺陷：

1. **ChEMBL 三态字段被误布尔化**（`chembl_ingest.py`）
   ChEMBL 的是/否字段是 **三态 `1`=是 / `0`=否 / `-1`=未知**。
   初版写 `bool(v[k])` —— **`bool(-1)` 是 `True`**，把「未知」全错标成「是」。
   已在 `--build` 修为「仅 0/1 写布尔」，`max_phase=-1`（不适用）也不再落属性。
2. **同一个三态坑在 `--check` 里漏改**（自查发现）
   `--check` 仍用 `if v.get(field)` 统计，导致**误报「孤儿药 262 个 / 首创药 262 个」**。
   `-1` 是 truthy。修后正确显示「孤儿药 0 个（未知 262）」——本条正是**「一个错误会污染整个
   下游统计」**的又一实例，也说明**校验代码本身也要被校验**。
