## 6. 已知限制

1. **CDN 需联网**：Cytoscape.js / MathJax 走公网 CDN；离线环境下会降级为
   纯文本图谱（不崩溃，但无图形渲染）。如需完全离线，可将两库 vendored 到本地
   并改用相对路径 `<script src>`。
2. **Neo4j 生产态待 JVM/数据库**：本 PoC 走 NetworkX 兜底（无需 JVM）。
   切 Neo4j 仅需把 `queries.get_backend` 改为 `auto` / `neo4j`，前端无需改动；
   Cypher 语句已在 `03_知识层/queries.cypher` 备好。
3. **22 节点 vs 36 节点口径**：`graph_data.json` 严格等于节点表 **22 节点**；
   但 Phase 3 的 11 条 LLM 假设边引用了 14 个**外部实体**
   （`MX:phy:*` / `MX:chem:*` / `MX:math:*` / `MX:sym:c`），未收录进 `nodes[]`。
   前端为这些端点合成 **ghost 节点**以显示全部 52 条边；NetworkX 后端则会将其
   隐式建点，故 `/api/stats` 报 **36 节点**。根治方式是在 Phase 2/3 的 ETL 中把
   外部实体一并注册为节点（已列入建议）。
4. **浏览器自动化受限**：本环境的受管浏览器导航被策略拦截，故图形渲染的
   可视化截图未获取；已改用 `node --check` + 数据契约校验 + 离线降级截图佐证。

## 7. 后续建议

- 在 ETL 中注册 LLM 假设涉及的外部实体，消除 ghost / 36-vs-22 口径差异。

- 假设提交入口对接 `04_验证闭环`（POST 候选边 → 待审队列 → 回写），完成闭环上游。
