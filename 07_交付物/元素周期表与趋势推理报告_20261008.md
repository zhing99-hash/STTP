## 一、为什么做这个

A7 原计划只是「`same_period`/`same_family` 桥接到物理量」。勘察后发现，**这两类边的数据基础本身就有三处硬伤**，不先修掉，"桥接"没有意义。于是本轮分两阶段：

- **阶段 1 · 数据基础**：周期表位置（period / group / block / series）对齐 IUPAC 权威表，并修正由数据源带进来的错误；
- **阶段 2 · 趋势推理**：把元素性质物理量化进图，再用周期/族分组做秩相关，**让图数据自己去"发现"周期律**。

## 二、发现的四个问题（均经全量核验，非抽样）

| # | 问题 | 实测 | 影响 |
| --- | --- | --- | --- |
| 1 | **`O` 的 `atomic_number = 16`**（应为 8） | 118 个元素中 **1 个错** | ElementKG `HASATOMIC` 语义混淆残留；A1 只修了符号解析，**属性值本身没修** |
| 2 | `period` 缺失 6 个 | Sc(21) / Ts(117) / B(5) / Mg(12) / Sn(50) / Au(79) | 周期性推理缺排序轴 |
| 3 | `group` 仅覆盖 **3/118** | C / H / O 三个（A5 合并时由别名并集补出） | 同族判定无属性依据 |
| 4 | **`same_family` 682 条中 308 条语义错误** | 真值应为 374 条 | ElementKG2.0 把「3 族(Sc/Y/La/Ac) + 镧系(Ce–Lu) + 锕系(Th–Lr)」并成一个 **32 元"族"** |

### 问题 4 的证据

对 `same_family` 边做并查集连通分量分析：

```
682 条边 → 18 个连通分量
分量大小分布: {4: 9, 6: 6, 7: 2, 32: 1}      ← 第 4 项是 32 元超大分量
32 元分量成员: ['Sc','Y','La','Ac'] + 镧系14 + 锕系14
```

而 IUPAC 18 族的真值结构是：`1族7 / 2族6 / 3族4 / 4–12族各4 / 13–17族各6 / 18族7`，加 f 区**独立**的镧系 14 + 锕系 14。按真值重算：

```
真值 same_family 全集: 374
现有 same_family:      682
  错误边（现有∉真值）: 308
  缺失边（真值∉现有）:   0     ← 纯多发，无遗漏
```

308 条错误边**全部是跨组边**（组内边正确保留）：镧系↔锕系 196、镧系/锕系↔3族 112。

### 反向证据：`same_period` 完全干净

```
1360 条边 → 恰好 7 个连通分量，大小 2/8/8/18/18/32/32   ← 完美对应周期表 7 周期
与权威周期矛盾: 0 条
```

（先前一度显示"8 条矛盾"，追查后确认是 `O` 的 `atomic_number=16` 把 O 误判成第三周期所致——修掉 Z 后矛盾归零。**一个错误的属性值会污染整个下游校验，这是本轮最值得记录的一课。**）

## 三、阶段 1 · 数据基础修复

### 3.1 权威参考表扩展（`11_真实数据/element_reference.py`）

新增 118 个元素的 `period` / `group` / `block` / `series` 四个字段，并提供 `period_of_z()` / `group_of_z()` / `block_of_z()` / `series_of_z()` / `members_of_group()` / `series_symbols()` 查询函数。

口径约定：
- **`group`**：IUPAC 18 族号；**f 区 28 个成员中，Ce–Lu 与 Th–Lr 不占族号**（`group=None`），由 `series` 表达；**La / Ac 计入 3 族**（与数据既有分量结构一致）。
- **`block`**：由 group 推导（He 特判归 s）+ f 区归 f。
- **`series`**：`lanthanide`（La–Lu 15）/ `actinide`（Ac–Lr 15）。

自检断言：周期员数 `[2,8,8,18,18,32,32]`、区块分布 `s14/p36/d40/f28`（合计 118）。

### 3.2 图谱修复（`03_知识层/normalize_periodic.py`）

| 字段 | 修复前 | 修复后 |
| --- | --- | --- |
| `atomic_number` | O=16 | **O=8**（原值保留在 `ek_atomic_raw`） |
| `period` | 112/118 | **118/118** |
| `group` | 3/118 | **90/118**（f 区 28 个中 14 个纯镧系/锕系无族号） |
| `block` | — | **118/118**（新增） |
| `series` | — | **30/118**（新增，f 区） |
| `periodic_source` | — | 118 个全部写入 `element_reference_iupac` |

**边修正**：删除 308 条语义错误的 `same_family` 边，682 → 374（= 真值）。

顺带收益：`same_period` / `same_family` 从「外部数据源给定的边」升级为「**可由权威属性派生的关系**」——现在满足 `same_family == 由 (group, series) 分组的组内两两组合`，可随时重新生成与校验。

### 3.3 源头修复（`11_真实数据/elementkg_ingest.py`）

**不改源头，下次重跑 ETL 会重新长出 308 条错边。** 三处修改：

1. `hasFamily*` → 用权威表的 `family_key()` 校正后再入边（跨族不入边）；
2. `hasPeriod*` → 周期号改由权威表给出（ElementKG 的值不采信）；
3. `hasAtomic` → `atomic_number` 一律以权威表为准（不再"仅在为空时补全"），并顺带写入 period/group/block/series。

重跑验证：`same_period 1355 + same_family 374 = 1729` 关系边，与图谱侧完全一致；O 的 Z=8；Ce/Lu 归 f 区、La/Ac 归 3 族。

## 四、阶段 2 · 周期性趋势推理

### 4.1 方法

把 12 项元素性质从「节点属性」升级为「图结构」：

- 新建物理量节点 `PQ:el:<property>`（`domain=chem.element_property`，12 个）
- 新增 `Element -[has_quantity]-> PQ:el:<property>` 边，**1089 条**，数值与单位落在边上
  （与既有 `Molecule -[has_quantity]-> PhysicalQuantity` 同构）

然后在**同周期 / 同族内沿原子序数**做 Spearman 秩相关（含并列秩平均），与教科书周期律比对。

单位说明：ElementKG 的 OWL **未标注任何单位**，下表由数值量级 + 化学常识推定，并经已知值核验（Os 密度 22590 → 22.59 g/cm³；Ag 热导率 429 W/(m·K)；H 比热 14300 J/(kg·K)），写入节点的 `unit_inferred=True` 标记来源。

| 第一电离能 | **+0.89** | 100% | 递增 | ✅ VERIFIED |
| 相对原子质量 | +1.00 | 100% | 递增 | ✅ VERIFIED |

### 4.3 9 条 CONTRADICTED 全部是**真实化学异常**，不是数据错误

逐条核对后确认——这正是「理论模型的适用边界」，是有价值的发现而非缺陷：

| 分组 | 成员与实测值 | 说明 |
| --- | --- | --- |
| 族 11 | Cu 1.90 → Ag 1.93 → **Au 2.54** | 真实：Au 电负性异常高（相对论效应） |
| 族 6 | Cr 1.66 → Mo 2.16 → **W 2.36** | 真实：第二/三过渡系异常 |
| 族 12 | Zn 1.65 → Cd 1.69 → **Hg 2.00** | 真实 |
| 族 10 | Ni 1.91 → Pd 2.20 → **Pt 2.28** | 真实 |
| 镧系 | Ce…Lu 递增 | 真实：镧系收缩 |
| 族 7 / 族 5 | Mn↔Tc↔Re / V↔Nb↔Ta | 真实：d 区异常 |

"同族电负性递减"是**主族规律**；d 区因镧系收缩与相对论效应普遍反向。数据准确反映了这一点。
