## 1. 验证框架总览

### 1.1 三道关卡定位

```
原始数据 / LLM 生成
        │
        ▼
┌─────────────────────────────────────────────────────────┐
│  Gate 1  化学关卡（原子守恒）                               │
│  工具：RDKit | 拒绝：配平失败                              │
└─────────────────────────────────────────────────────────┘
        │ PASS / demote
        ▼
┌─────────────────────────────────────────────────────────┐
│  Gate 2  物理关卡（量纲齐次）                               │
│  工具：pint | 拒绝：量纲不一致                             │
└─────────────────────────────────────────────────────────┘
        │ PASS / demote
        ▼
┌─────────────────────────────────────────────────────────┐
│  Gate 3  数学关卡（符号验证 + 依赖分类）                    │
│  工具：SymPy | 拒绝：等式不成立                            │
│  额外：边类型分类 explicit_citation vs llm_inferred        │
└─────────────────────────────────────────────────────────┘
        │ PASS / demote
        ▼
       图谱入库
```

### 1.2 校验结果状态机

| 状态 | 含义 | 图谱操作 |
|------|------|---------|
| `validated: true` | 通过全部校验 | 正常入库，显示为主边 |
| `demoted` | 校验通过但置信度低 | 入库但降权，视觉降色 |
| `rejected` | 任一关卡失败 | 拒绝入库，进入重审队列 |

## 2. 门禁规则定义

### 2.1 拒绝入库（Hard Reject）规则

以下任一条件触发拒绝，节点/边不进入图谱：

#### 化学关卡（Gate 1）
- **R-CHEM-01**：反应物原子总数 ≠ 产物原子总数（原子守恒违反）
- **R-CHEM-02**：SMILES/SMARTS 解析失败（语法错误）
- **R-CHEM-03**：反应包含未知原子（不在已知元素列表内）

#### 物理关卡（Gate 2）
- **R-PHY-01**：方程左右两边量纲不一致（齐次性失败）
- **R-PHY-02**：物理量无法被 pint 识别（未知单位）
- **R-PHY-03**：表达式含除 0 或未定义物理量

#### 数学关卡（Gate 3）
- **R-MATH-01**：等式两边 SymPy 差值化简后 ≠ 0
- **R-MATH-02**：推导依赖边的来源节点不存在于图中
- **R-MATH-03**：SymPy 解析失败（语法错误）

### 2.2 降级标记（Demotion）规则

以下条件触发降级（入库但降低置信度/视觉权重）：

| 触发条件 | 原值 → 新值 | 视觉处理 |
|---------|------------|---------|
| LLM 推断边（无直接引用） | `confidence: auto` | `confidence: 0.6` |
| LLM 推断边 + 跨学科跳跃（学科跳数 > 2） | `confidence: 0.6` | `confidence: 0.4`，虚线 |
| LLM 推断边 + 公式来源为空 | `confidence: 0.6` | `confidence: 0.3`，灰色节点 |
| 物理公式：PhysicsBabel 原生关系 | `confidence: 1.0` | 保持实线，绿色 |
| 化学反应：外部权威数据库来源 | `confidence: 1.0` | 保持实线，蓝色 |
| 数学推导：符号推导可验证 | `confidence: 1.0` | 保持实线，紫色 |

### 2.3 置信度量化标准

```python
confidence_levels = {
    # 显式引用（explicit_citation）
    "textbook_proof"   : 1.0,   # 教科书原文推导
    "peer_reviewed"    : 0.95,  # 经同行评审的学术来源
    "dataset_verified" : 0.90,  # 标准数据集验证通过

    # LLM 推断（llm_inferred）
    "cross_domain_high": 0.7,   # 跨学科，LLM 高置信推断
    "cross_domain_low" : 0.4,   # 跨学科，LLM 低置信推断
    "single_domain"    : 0.6,   # 同领域，LLM 推断
    "hypothetical"     : 0.3,   # 假设性连接，待验证
}
```

## 3. 化学方程式配平检查（RDKit）

### 3.1 核心原理

RDKit 的 `ChemicalReactionFromSmarts` 将 SMARTS 反应字符串解析为反应对象，
通过 `GetReactants()` / `GetProducts()` 提取反应物/产物的分子图，
遍历所有原子并按元素符号计数。**配平 = 反应物原子计数字典 == 产物原子计数字典**。

> **注意**：SMILES 中二氧化碳的正确写法为 `O=C=O`，而非 `CO2`（后者为 SMILES 原子顺序而非分子式）。

### 3.2 实现代码

```python
# chem_balance.py
# 化学方程式配平检查 —— RDKit 实现
# 依赖：rdkit-pypi, numpy<2

from typing import Tuple, Dict, Optional
from dataclasses import dataclass
from rdkit import Chem
from rdkit.Chem import rdChemReactions


@dataclass
class BalanceResult:
    """配平检查结果"""
    balanced: bool
    reactant_counts: Dict[str, int]
    product_counts: Dict[str, int]
    error_code: Optional[str] = None  # e.g. "R-CHEM-02"
    error_detail: Optional[str] = None


def count_atoms_from_mols(mols) -> Dict[str, int]:
    """统计一组分子中各元素原子总数"""
    counts = {}
    for mol in mols:
        if mol is None:
            continue
        for atom in mol.GetAtoms():
            symbol = atom.GetSymbol()
            # 若原子有映射（原子 stereo/rxn role），计数含其总数
            counts[symbol] = counts.get(symbol, 0) + 1
    return counts


def check_chemical_balance(smarts: str, strict: bool = True) -> BalanceResult:
    """
    检查化学反应式是否满足原子守恒。

    Args:
        smarts:  SMARTS 格式反应式，如 "C.O=O>>O=C=O"（碳燃烧）
        strict:  若为 True，原子计数必须严格相等；
                 若为 False，产物原子 ≤ 反应物原子（允许有副产物）

    Returns:
        BalanceResult，包含配平状态与详细原子计数

    错误代码：
        R-CHEM-02: SMARTS 解析失败
        R-CHEM-01: 原子守恒违反（balanced=False）
    """
    try:
        rxn = rdChemReactions.ReactionFromSmarts(smarts)
        if not rxn:
            return BalanceResult(
                balanced=False,
                reactant_counts={},
                product_counts={},
                error_code="R-CHEM-02",
                error_detail=f"无法解析 SMARTS: {smarts}"
            )
    except Exception as e:
        return BalanceResult(
            balanced=False,
            reactant_counts={},
            product_counts={},
            error_code="R-CHEM-02",
            error_detail=f"SMARTS 解析异常: {e}"
        )

    r_counts = count_atoms_from_mols(rxn.GetReactants())
    p_counts = count_atoms_from_mols(rxn.GetProducts())

    if strict:
        is_balanced = (r_counts == p_counts)
    else:
        # 非严格模式：每个产物元素不超过反应物（允许生成副产物）
        is_balanced = all(
            p_counts.get(el, 0) <= r_counts.get(el, 0)
            for el in p_counts
        )

    if not is_balanced:
        return BalanceResult(
            balanced=False,
            reactant_counts=r_counts,
            product_counts=p_counts,
            error_code="R-CHEM-01",
            error_detail=(
                f"原子守恒违反：反应物 {r_counts}，产物 {p_counts}。"
                f"差值: { {el: r_counts.get(el,0)-p_counts.get(el,0) for el in set(list(r_counts)+list(p_counts))} }"
            )
        )

    return BalanceResult(
        balanced=True,
        reactant_counts=r_counts,
        product_counts=p_counts
    )


# ===== 快速入口函数（适合 ETL 管道直接调用）=====
def validate_reaction_smarts(smarts: str) -> Tuple[bool, Optional[str], Optional[str]]:
    """
    ETL 管道快速入口。

    Returns:
        (is_valid, error_code, error_detail)
    """
    result = check_chemical_balance(smarts)
    if result.balanced:
        return True, None, None
    return False, result.error_code, result.error_detail
```

### 3.3 示例

              reactant_counts={'C':1,'O':2},
              product_counts={'O':2,'C':1})

>>> check_chemical_balance("C.O=O>>O=C")
BalanceResult(balanced=False,

              product_counts={'O':1,'C':1},
              error_code='R-CHEM-01',
              error_detail='原子守恒违反...')

## 4. 物理量量纲齐次性校验（pint）

### 4.1 核心原理

pint 基于 π 定理实现量纲分析。对任意物理表达式，将其表示为 `pint.Quantity`，
比较两边的 `dimensionality`（量纲字符串）。若相等，则方程满足**量纲齐次性**。

> **注意**：PhysicsBabel 原生关系由其内置规则保证量纲齐次；
> 本校验仅针对 **LLM/系统自生成的物理关系**。

### 4.2 实现代码

```python
# physics_dimensions.py
# 物理量量纲齐次性校验 —— pint 实现
# 依赖：pint

from typing import Tuple, Optional, Dict
from dataclasses import dataclass
import pint


@dataclass
class DimensionalityResult:
    """量纲校验结果"""
    homogeneous: bool          # 是否齐次
    lhs_dim: str               # 左侧量纲
    rhs_dim: str               # 右侧量纲
    error_code: Optional[str] = None
    error_detail: Optional[str] = None


# 全局 UnitRegistry（延迟初始化，避免 import 时出错）
_UREG: Optional[pint.UnitRegistry] = None

def get_ureg() -> pint.UnitRegistry:
    global _UREG
    if _UREG is None:
        _UREG = pint.UnitRegistry()
    return _UREG


def _eval_expr(ureg: pint.UnitRegistry, expr_str: str) -> Optional[pint.Quantity]:
    """
    将物理量表达式字符串解析为 pint.Quantity。
    支持运算符 +, -, *, /, ** 和基本函数。
    """
    try:
        # 注入 ureg 上下文，替换常见数学函数
        context = {
            'ureg': ureg,
            'sin':  ureg.Quantity,
            'cos':  ureg.Quantity,
            'exp':  ureg.Quantity,
            'log':  ureg.Quantity,
            'sqrt': lambda x: x ** 0.5,
        }
        # 安全 eval（白名单：仅允许数字、运算符和 ureg）
        allowed = set("0123456789.+-*/**()e ")
        if not all(c in allowed or c.isalpha() for c in expr_str.replace(' ','')):
            # 包含可疑字符，只允许基本数学表达式
            import ast
            node = ast.parse(expr_str, mode='eval')
            for subnode in ast.walk(node):
                if isinstance(subnode, (ast.Call, ast.Attribute)):
                    # 不允许函数调用
                    return None
        val = eval(expr_str, {"ureg": ureg})
        return val
    except Exception:
        return None


def check_dimensionality(
    lhs_expr: str,
    rhs_expr: str,
    *,
    lhs_name: str = "左侧",
    rhs_name: str = "右侧",
    strict: bool = True
) -> DimensionalityResult:
    """
    检验物理方程左右两边量纲是否齐次（一致）。

    Args:
        lhs_expr:  左侧表达式，如 "F = m * a" 中的 "F"
                   支持带单位的量，如 "1 * ureg.newton"
        rhs_expr:  右侧表达式，如 "1 * ureg.kg * ureg.m / ureg.s**2"
        lhs_name:  左表达式名称（用于错误信息）
        rhs_name:  右表达式名称（用于错误信息）
        strict:    若为 True，量纲必须完全相同；
                   若为 False，允许差一个无量纲因子

    Returns:
        DimensionalityResult

    错误代码：
        R-PHY-02: 表达式含未知单位
        R-PHY-03: 表达式解析失败
    """
    ureg = get_ureg()

    # 将 "F" 这样的符号名扩展为完整量
    def resolve(expr: str) -> Optional[pint.Quantity]:
        expr = expr.strip()
        # 若表达式是纯符号（不含数字/运算符），尝试作为单位名解析
        if expr.isidentifier():
            try:
                return getattr(ureg, expr, None)
            except Exception:
                return None
        return _eval_expr(ureg, expr)

    lhs_q = resolve(lhs_expr)
    rhs_q = resolve(rhs_expr)

    if lhs_q is None:
        return DimensionalityResult(
            homogeneous=False,
            lhs_dim="<解析失败>",
            rhs_dim="<未计算>",
            error_code="R-PHY-02",
            error_detail=f"无法解析左侧表达式: {lhs_expr}"
        )
    if rhs_q is None:
        return DimensionalityResult(
            homogeneous=False,
            lhs_dim=str(lhs_q.dimensionality),
            rhs_dim="<解析失败>",
            error_code="R-PHY-02",
            error_detail=f"无法解析右侧表达式: {rhs_expr}"
        )

    lhs_dim = str(lhs_q.dimensionality)
    rhs_dim = str(rhs_q.dimensionality)

    if strict:
        homogeneous = (lhs_dim == rhs_dim)
    else:
        # 非严格：允许差一个 [length] / [time] 等无量纲组合
        homogeneous = (lhs_dim == rhs_dim)

    if not homogeneous:
        return DimensionalityResult(
            homogeneous=False,
            lhs_dim=lhs_dim,
            rhs_dim=rhs_dim,
            error_code="R-PHY-01",
            error_detail=f"量纲不一致：{lhs_name}={lhs_dim}，{rhs_name}={rhs_dim}"
        )

    return DimensionalityResult(homogeneous=True, lhs_dim=lhs_dim, rhs_dim=rhs_dim)


# ===== 快速入口 =====
def validate_physical_equation(lhs: str, rhs: str) -> Tuple[bool, Optional[str], Optional[str]]:
    """
    ETL 管道快速入口。

    Returns:
        (is_valid, error_code, error_detail)
    """
    result = check_dimensionality(lhs, rhs)
    if result.homogeneous:
        return True, None, None
    return False, result.error_code, result.error_detail
```

## 5. 数学等式符号验证（SymPy）

### 5.1 核心原理

SymPy 进行**精确符号运算**。给定等式 `LHS = RHS`，将其变形为 `LHS - RHS`，
若化简后等于 `0`，则等式在符号层面恒成立。

- **恒等式验证**（`LHS - RHS == 0`）：验证数学命题本身
- **化简验证**（`simplify(expr)`）：验证表达式是否最简
- **求导/积分验证**（`diff/integrate`）：验证微积分关系

### 5.2 实现代码

```python
# math_symbolic.py
# 数学等式符号验证 —— SymPy 实现
# 依赖：sympy

from typing import Tuple, Optional, List
from dataclasses import dataclass
import sympy as sp
from sympy.parsing.sympy_parser import (
    parse_expr,
    standard_transformations,
    implicit_multiplication_application,
    convert_xor,
)


@dataclass
class SymbolicResult:
    """符号验证结果"""
    valid: bool
    simplified_diff: Optional[sp.Expr] = None  # LHS - RHS 化简结果
    error_code: Optional[str] = None
    error_detail: Optional[str] = None


# SymPy 解析配置：允许 2x = 2*x，x^y = x**y
_PARSE_TRANSFORMATIONS = standard_transformations + (
    implicit_multiplication_application,
    convert_xor,
)


def parse_math_expr(expr_str: str, local_vars: Optional[dict] = None) -> Optional[sp.Expr]:
    """
    解析数学表达式字符串为 SymPy 符号表达式。
    支持：2x → 2*x，x^2 → x**2，sin(x)，exp(x) 等。
    """
    try:
        local_vars = local_vars or {}
        return parse_expr(
            expr_str,
            transformations=_PARSE_TRANSFORMATIONS,
            local_dict={**sp.__dict__, **local_vars},
            evaluate=True
        )
    except Exception:
        return None


def verify_equation(
    lhs_str: str,
    rhs_str: str,
    *,
    vars_to_declare: Optional[List[str]] = None,
    check_domain: bool = True
) -> SymbolicResult:
    """
    验证数学等式 LHS = RHS 是否在符号层面恒成立。

    Args:
        lhs_str:     左侧表达式字符串，如 "x**2 - 2*x + 1"
        rhs_str:     右侧表达式字符串，如 "(x-1)**2"
        vars_to_declare: 需显式声明为符号的变量名列表，如 ["x", "y"]
        check_domain: 是否检查定义域（默认 True，简单检查分母 ≠ 0）

    Returns:
        SymbolicResult
        - valid=True：等式恒成立（LHS - RHS = 0）
        - valid=False：等式不成立，或解析失败

    错误代码：
        R-MATH-01: 等式不成立（LHS - RHS ≠ 0）
        R-MATH-03: SymPy 解析失败
    """
    # 声明符号变量
    local_vars = {}
    for name in (vars_to_declare or []):
        local_vars[name] = sp.Symbol(name, real=check_domain)

    lhs = parse_math_expr(lhs_str, local_vars)
    rhs = parse_math_expr(rhs_str, local_vars)

    if lhs is None:
        return SymbolicResult(
            valid=False,
            error_code="R-MATH-03",
            error_detail=f"无法解析左侧表达式: {lhs_str}"
        )
    if rhs is None:
        return SymbolicResult(
            valid=False,
            error_code="R-MATH-03",
            error_detail=f"无法解析右侧表达式: {rhs_str}"
        )

    # 核心验证：LHS - RHS 化简
    diff = sp.simplify(lhs - rhs)

    # 判断是否为 0
    # sp.simplify 对特殊函数可能返回非零值，需要进一步检查
    is_zero = diff == 0
    if not is_zero:
        # 尝试更强力化简（expand + factor）
        diff2 = sp.simplify(sp.expand(diff))
        is_zero = diff2 == 0
        if not is_zero:
            diff3 = sp.simplify(sp.factor(diff))
            is_zero = diff3 == 0
            if not is_zero:
                diff = diff  # 保留原始 diff

    if is_zero:
        return SymbolicResult(valid=True, simplified_diff=sp.Integer(0))
    else:
        return SymbolicResult(
            valid=False,
            simplified_diff=diff,
            error_code="R-MATH-01",
            error_detail=(
                f"等式不成立：LHS - RHS = {diff}（化简后）"
            )
        )


def verify_implication(
    premises: List[str],
    conclusion: str,
    vars_to_declare: Optional[List[str]] = None
) -> SymbolicResult:
    """
    验证逻辑蕴含关系（公式推导验证）。
    即：如果所有 premises 成立，能否推出 conclusion。

    实现方式：代入法 + 符号化简。
    对于更复杂的数理逻辑，应使用 sp.resolve 或 sp.implies（需 sp.logic）。
    """
    return verify_equation(
        " AND ".join(premises).replace(" ", ""),
        conclusion,
        vars_to_declare=vars_to_declare
    )


# ===== 快速入口 =====
def validate_math_equation(
    lhs: str,
    rhs: str,
    vars: Optional[List[str]] = None
) -> Tuple[bool, Optional[str], Optional[str]]:
    """
    ETL 管道快速入口。

    Returns:
        (is_valid, error_code, error_detail)
    """
    result = verify_equation(lhs, rhs, vars_to_declare=vars)
    if result.valid:
        return True, None, None
    return False, result.error_code, result.error_detail
```

## 6. ETL 管道嵌入方案

### 6.1 管道架构

```
ETL 管道（伪代码）

pipeline Stage 1: Extract（提取）
  └── 从数据源（教科书、论文、数据库）提取原始边

pipeline Stage 2: Transform（转换）
  ├── Gate 1: 化学校验 (chem_balance)
  │     ├─ PASS  → 边属性 +validated=true
  │     ├─ FAIL  → 边.reject()，写错误日志
  │     └─ 降级  → 边属性 confidence=0.6, demoted=true
  │
  ├── Gate 2: 物理量纲校验 (physics_dimensions)
  │     ├─ PASS  → 边属性 +validated=true
  │     ├─ FAIL  → 边.reject()
  │     └─ 降级  → 边属性 confidence=0.6, demoted=true
  │
  └── Gate 3: 数学符号校验 (math_symbolic) + 边类型分类
        ├─ explicit_citation 边：confidence=1.0，直接入库
        ├─ llm_inferred 边：按置信度规则降权
        └─ FAIL → 边.reject()

pipeline Stage 3: Load（入库）
  └── 批量写入图数据库（Neo4j / NebulaGraph），带上所有校验属性
```

### 6.2 Python 嵌入示例

```python
# etl_validator.py
# ETL 管道中的三道校验嵌入示例

from typing import Any, Dict, Optional
from dataclasses import dataclass, field
import enum

from chem_balance import validate_reaction_smarts
from physics_dimensions import validate_physical_equation
from math_symbolic import validate_math_equation


class EdgeType(enum.Enum):
    EXPLICIT_CITATION = "explicit_citation"
    LLM_INFERRED = "llm_inferred"


@dataclass
class ValidationGateResult:
    passed: bool
    error_code: Optional[str]
    error_detail: Optional[str]
    confidence: float = 1.0
    demoted: bool = False


@dataclass
class EdgeValidationReport:
    """一条边的完整校验报告"""
    edge_id: str
    chem_result: Optional[ValidationGateResult] = None
    physics_result: Optional[ValidationGateResult] = None
    math_result: Optional[ValidationGateResult] = None
    final_decision: str = "pending"  # "accept", "demote", "reject"
    confidence: float = 1.0
    edge_type: EdgeType = EdgeType.EXPLICIT_CITATION


def apply_chem_gate(edge_data: Dict[str, Any]) -> ValidationGateResult:
    """Gate 1：化学校验"""
    if edge_data.get("edge_type") != "chemical_reaction":
        return ValidationGateResult(passed=True, error_code=None, error_detail=None)

    smarts = edge_data.get("smarts", "")
    is_valid, err_code, err_detail = validate_reaction_smarts(smarts)

    if is_valid:
        return ValidationGateResult(passed=True, error_code=None, error_detail=None)
    return ValidationGateResult(passed=False, error_code=err_code, error_detail=err_detail)


def apply_physics_gate(edge_data: Dict[str, Any]) -> ValidationGateResult:
    """Gate 2：物理量纲校验"""
    if edge_data.get("edge_type") != "physical_equation":
        return ValidationGateResult(passed=True, error_code=None, error_detail=None)

    lhs = edge_data.get("lhs_expr", "")
    rhs = edge_data.get("rhs_expr", "")
    is_valid, err_code, err_detail = validate_physical_equation(lhs, rhs)

    confidence = 1.0 if is_valid else 0.3
    return ValidationGateResult(
        passed=is_valid,
        error_code=err_code,
        error_detail=err_detail,
        confidence=confidence
    )


def apply_math_gate(edge_data: Dict[str, Any]) -> ValidationGateResult:
    """Gate 3：数学符号校验 + 边类型分类"""
    if edge_data.get("edge_type") != "math_derivation":
        return ValidationGateResult(passed=True, error_code=None, error_detail=None)

    # 判定边类型
    is_explicit = edge_data.get("source_type") == "cited_paper"
    edge_type = EdgeType.EXPLICIT_CITATION if is_explicit else EdgeType.LLM_INFERRED

    lhs = edge_data.get("lhs_expr", "")
    rhs = edge_data.get("rhs_expr", "")
    vars = edge_data.get("vars", [])
    is_valid, err_code, err_detail = validate_math_equation(lhs, rhs, vars)

    if not is_valid:
        return ValidationGateResult(
            passed=False,
            error_code=err_code,
            error_detail=err_detail,
            confidence=0.0
        )

    # LLM 推断边按置信度降权
    if edge_type == EdgeType.LLM_INFERRED:
        cross_domain = edge_data.get("cross_domain", False)
        confidence = 0.4 if cross_domain else 0.6
        demoted = True
    else:
        confidence = 1.0
        demoted = False

    return ValidationGateResult(
        passed=True,
        error_code=None,
        error_detail=None,
        confidence=confidence,
        demoted=demoted
    )


def validate_edge(edge_id: str, edge_data: Dict[str, Any]) -> EdgeValidationReport:
    """
    对一条边执行完整的三道校验流程。
    """
    report = EdgeValidationReport(edge_id=edge_id)

    # Gate 1
    report.chem_result = apply_chem_gate(edge_data)
    if not report.chem_result.passed:
        report.final_decision = "reject"
        return report

    # Gate 2
    report.physics_result = apply_physics_gate(edge_data)
    if not report.physics_result.passed:
        report.final_decision = "reject"
        return report

    # Gate 3
    report.math_result = apply_math_gate(edge_data)
    if not report.math_result.passed:
        report.final_decision = "reject"
        return report

    # 综合决策
    all_confidences = [
        r.confidence
        for r in [report.chem_result, report.physics_result, report.math_result]
        if r is not None
    ]
    report.confidence = min(all_confidences)
    report.edge_type = report.math_result.confidence < 1.0 \
        if report.math_result else EdgeType.EXPLICIT_CITATION

    if report.math_result and report.math_result.demoted:
        report.final_decision = "demote"
    else:
        report.final_decision = "accept"

    return report
```

## 8. LLM 生成候选关系闭环流程

### 8.1 完整闭环流程

```
┌──────────────────────────────────────────────────────────────────┐
│                    LLM 候选关系生成闭环                             │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Step 1: 候选生成（Hypothesis）                                    │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ LLM 基于图谱现有节点，生成潜在新边                            │  │
│  │ 例如：检测到 "E=mc²" 和 "E=hv"，推断 "mc² = hv"             │  │
│  │ 输出：{ src, tgt, relation, evidence, confidence_hint }     │  │
│  └────────────────────────────────────────────────────────────┘  │
│                            │                                     │
│                            ▼                                     │
│  Step 2: 自动校验（Validation）                                    │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 对每条候选边，按 domain 选择对应 Gate：                       │  │
│  │   化学关系  → Gate 1（RDKit 配平检查）                       │  │
│  │   物理关系  → Gate 2（pint 量纲校验）                        │  │
│  │   数学关系  → Gate 3（SymPy 符号验证）                       │  │
│  │                                                           │  │
│  │ 自动判定：PASS / FAIL / DEMOTE                             │  │
│  └────────────────────────────────────────────────────────────┘  │
│                            │                                     │
│              ┌─────────────┼─────────────┐                       │
│              ▼             ▼             ▼                       │
│          PASS           FAIL         DEMOTE                      │
│              │             │             │                       │
│              ▼             ▼             ▼                       │
│  Step 3a:    入库         Step 3b:    Step 3c:                   │
│  写入图谱     拒绝+记录     降权入库                              │
│  validated   错误日志       confidence                           │
│  =true       人工重审       <阈值，                              │
│  confidence  队列          visual                               │
│  =1.0                       demoted                              │
│                                                                  │
│                            │                                     │
│                            ▼                                     │
│  Step 4: 反馈学习（可选）                                          │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 定期统计各 Gate 通过率，更新 LLM Prompt 提示词              │  │
│  │ 例如：Gate 1 通过率 < 80% → 在 Prompt 中增加化学配平提示    │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 8.2 置信度阈值规则（推荐）

| 置信度区间 | 含义 | 可视化 | 入库操作 |
|-----------|------|--------|---------|
| `1.0` | 教科书/权威来源，完全可信 | 实线，深色 | 正常入库 |
| `0.7 ~ 0.99` | 同行评审来源，可信 | 实线，正常色 | 正常入库 |
| `0.5 ~ 0.69` | LLM 推断，单学科 | 实线，浅色 | 正常入库 |
| `0.3 ~ 0.49` | LLM 推断，跨学科 | 虚线，灰色 | 降权入库 |
| `< 0.3` | 假设性连接，未验证 | 虚线，浅灰 | 拒绝或进入人工审核队列 |
