## 2. 组件用途与安装方式

### 2.1 Python（基础）
- **用途**：统一运行环境，承载所有脚本与库。
- **安装**：从 https://www.python.org/downloads/ 安装 3.11.x；建议用 `venv` 隔离。
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
```

### 2.2 Neo4j（生产图库）
- **用途**：存储 Schema v0.1 的异构图，Cypher 做推导路径/反应网络查询，导出供 GNN 训练。
- **安装（桌面版，推荐本地开发）**：
  - 下载 Neo4j Desktop：https://neo4j.com/download/
  - 新建 Local DBMS，设置密码，版本选 5.x。
- **Docker 方式（可复现）**：
```bash
docker run -d --name formula-graph \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/yourpassword \
  neo4j:5.21
```
- **Python 驱动**：
```bash
pip install neo4j==5.21.0
```

### 2.3 NetworkX（原型）
- **用途**：小数据图建模、Schema 自洽性检查、快速算法验证。
```bash
pip install networkx==3.4.2
```

### 2.4 SymPy（符号计算）
- **用途**：公式 `canonical_form` 规范化、等价性判定、自动微分，支撑 `dimensionally_consistent` 与 LLM 假设校验闭环。
```bash
pip install sympy==1.13.1
```

### 2.5 pint（量纲）
- **用途**：解析 `PhysicalQuantity.dimensions`，对公式两侧做量纲一致性校验。
```bash
pip install pint==0.24.1
```

### 2.6 RDKit（化学信息）
- **用途**：解析 SMILES/InChI、生成分子指纹、反应 SMILES 处理（化学反应超图）。
- **安装**（conda 最稳，也可用 pip wheel）：
```bash
# conda（推荐）
conda install -c conda-forge rdkit==2024.03.1
# 或 pip wheel
pip install rdkit-pypi==2024.3.1
```

### 2.7 LLM API（假设生成）
- **用途**：从公式/概念文本生成候选推导依赖（`llm_inferred`）、抽取概念与符号、辅助反应机理分类。
- **安装**：
```bash
pip install openai==1.50.0
```
- **配置**：设置环境变量 `OPENAI_API_KEY`，建议封装统一 `call_llm(prompt)` 接口，便于切换模型与做限流/重试。

### 2.8 前端可视化（Cytoscape.js / D3.js）
- **用途**：交互式图谱展示（节点拖拽、路径高亮、按 `confidence` 渐变着色）。
- **安装**：前端通过 npm 引入，或 CDN 直引。
```bash
npm install cytoscape@3.30.0 d3@7.9.0
```
```html
<!-- 或 CDN -->
<script src="https://cdn.jsdelivr.net/npm/cytoscape@3.30.0/dist/cytoscape.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/d3@7.9.0/dist/d3.min.js"></script>
```

### 2.9 PyTorch Geometric（GNN，推理生成层）
- **用途**：对异构图谱做节点/边嵌入，链接预测推荐“候选推导边”，形成假设生成。
```bash
pip install torch==2.3.1 pytorch-geometric==2.5.3
```

### 2.10 辅助库
```bash
pip install pydantic==2.9.2 python-dotenv==1.0.1 requests==2.32.3 prefect==2.20.0
```

## 3. 本地开发环境搭建清单（Step-by-Step）

1. **装 Python 3.11** 并创建虚拟环境 `.venv`，激活。
2. **安装 Neo4j**（Desktop 或 Docker），启动，访问 `http://localhost:7474`，确认可登录。
3. **建立项目根目录** `01tuopu/`，下设：
   - `01_架构与数据模型/`（本批文档）
   - `02_数据采集/`、`03_知识层/`、`04_推理生成/`、`05_交互层/`、`scripts/`、`notebooks/`
4. **安装 Python 依赖**（见 §2 各 `pip install`，建议汇总到 `requirements.txt`）：
   ```bash
   pip install -r requirements.txt
   ```
5. **配置 `.env`**（不入仓）：
   ```
   NEO4J_URI=bolt://localhost:7687
   NEO4J_USER=neo4j
   NEO4J_PASSWORD=yourpassword
   OPENAI_API_KEY=sk-...
   ```
6. **初始化 Schema**：在 Neo4j 执行唯一性约束与索引（见《图Schema_v0.1.md》§6）：
   ```cypher
   CREATE CONSTRAINT FOR (n:Formula) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:Symbol) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:PhysicalQuantity) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:Molecule) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:Element) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:Reaction) REQUIRE n.id IS UNIQUE;
   CREATE CONSTRAINT FOR (n:MathConcept) REQUIRE n.id IS UNIQUE;
   ```
7. **跑通最小闭环（Hello Graph）**：
   - 用 NetworkX 构造 1 条 `Formula` + `Symbol` + `has_symbol` 边，验证 Schema 规则。
   - 用 SymPy 对 1 个公式做 `canonical_form`，用 pint 做 1 次量纲校验，生成 `dimensionally_consistent` 边。
   - 调一次 LLM 生成 1 条 `llm_inferred` `derived_from` 边，标注低 `confidence`。
   - 将上述节点/边写入 Neo4j，Cypher 查询验证。
8. **前端冒烟测试**：用 Cytoscape.js 加载上述子图 JSON，确认可渲染、可按 `confidence` 着色。
9. **（可选）GNN 预热**：用 PyG 加载子图做节点分类，验证推理生成层通路。

## 5. 版本与兼容性注意

- **Python 3.11 与 RDKit**：优先 conda 安装；纯 pip 用 `rdkit-pypi` wheel。
- **Neo4j 5.x 与驱动**：务必用 `neo4j` Python 驱动 5.x，Cypher 语法与 4.x 大体兼容。
- **PyG 与 torch**：版本需匹配（PyG 2.5 对应 torch 2.3），避免 CUDA 版本错配。
- **LLM API**：通过统一封装层调用，模型可热切换，避免业务代码耦合具体厂商。
- **可视化**：Cytoscape.js 适合关系图；D3.js 适合高度定制/量级大的力导向；二者可并存。
